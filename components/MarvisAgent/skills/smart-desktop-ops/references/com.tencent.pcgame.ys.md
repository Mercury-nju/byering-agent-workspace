# 原神 桌面应用操作规范

## 0. 应用概述

**应用类型**：native（原生 Windows 应用）

安装流程为二阶段：**先安装米哈游启动器 → 再通过启动器下载安装原神游戏本体**。
`name_cue(action="launch")`仅能启动米哈游启动器。下载安装完成后，在启动器中选择原神并点击"开始游戏"。

**窗口特征**：
- **米哈游启动器窗口**：独立窗口，左侧有游戏列表（原神、崩坏星穹铁道等），右侧为选中游戏的详情页面，右下方有"获取游戏"或"开始游戏"按钮
- **安装程序窗口**：下载启动器安装包后运行，显示黄色"快速安装"按钮和"自定义安装"选项。需先点击左下角"同意"文字位置完成协议勾选（直接点击"同意"二字即可），再点击"快速安装"按钮开始安装

## 0.1 参数规则

**本 App 常用窗口名**（不同阶段窗口名不同，详见 SKILL.md 参考表）：
- 安装程序阶段：`app_name="HoYoPlay"` 或 `app_name="米哈游"`
- 启动器阶段：`app_name="HoYoPlay"` 或 `app_name="米哈游启动器"`
- 游戏主体阶段：`app_name="原神"` 或 `app_name="Genshin Impact"`

**App 特有规则**：
1. **严格禁止使用 `exe_capture_screen`**（覆盖通用规范）：所有操作必须围绕 `exe_capture_window` / `exe_dump_ui` 展开。
2. **启动/打开任何窗口后必须先将其置顶**：通过 `exe_focus_window(app_name="...")` 将目标窗口前置。

## 1. 核心操作流程：下载并安装原神

⚠️ **【二阶段安装】** 原神安装分两个阶段：①安装米哈游启动器 → 通过启动器下载安装原神游戏本体。两步缺一不可。

### 1.1 阶段一：下载并安装米哈游启动器

⚠️ 如果 `name_cue(action="launch", name="原神")` 可成功启动，说明已安装，跳过此阶段直接进入 §1.2。

```

  │   │
  │   ├─ 3a. 窗口置顶 + 截图确认安装程序界面
  │   │   ├─ wait 5000ms → exe_focus_window(app_name="米哈游") → exe_capture_window(app_name="米哈游")

  │   │

  │   │   └─ exe_capture_window 截图验证复选框已勾选
  │   │
  │   ├─ 3c. 点击"快速安装"按钮
  │   │   ├─ exe_dump_ui OCR 定位"快速安装" → exe_action_pipeline 点击
  │   │   ├─ wait 3000ms
  │   │   └─ exe_capture_window 截图验证安装已开始
  │   │
  │   └─ 3d. 等待安装完成（每隔 5 秒截图检查进度）
```

### 1.4 注意事项

- **磁盘空间**：原神本体约 80-100GB，安装前务必确认目标磁盘有足够空间（≥ 120GB）
- **网络要求**：下载原神需要稳定的网络连接，建议有线网络
- **下载时间**：因文件较大，下载可能需要数十分钟到数小时，取决于网速
- **UAC 弹窗**：安装启动器时大概率触发 UAC 弹窗，需通知用户接管
- **安装路径**：建议安装到非 C 盘的大容量磁盘以节省系统盘空间
- **🔴 路径更改须用户操作**：如遇磁盘空间不足需要更改安装路径，必须暂停并通知用户手动更改，不要自行操作路径修改（详见 §2.2）
- **断点续传**：米哈游启动器支持断点续传，如下载中断可重新打开启动器继续下载

### 1.5 App 特有操作规范

- **焦点管理**：米哈游启动器和安装程序为自定义 UI 框架，`window_x/y` 为 `-32000`（或 < -10000）表示窗口已最小化，用 `exe_focus_window` 置顶恢复。

## 2. 特殊场景处理

### 2.1 UAC 权限弹窗

安装米哈游启动器时**几乎必定触发** UAC，参见通用规范「中断处理 > 用户接管型」。

### 2.2 磁盘空间不足 / 安装路径需要更改

🔴🔴 **【用户主动操作场景】** 当遇到磁盘空间不足或需要更改安装路径时，**必须暂停操作并通知用户**，由用户手动完成路径修改。AI 不应自行尝试点击"更改"按钮或修改路径输入框。

- 如果启动器提示磁盘空间不足（如红色警告"当前磁盘空间不足"）：
  1. **立即暂停当前操作**，不要尝试自行更改路径
  2. **向用户清晰说明问题**：
     - 当前安装路径及所在磁盘
     - 当前磁盘剩余空间
     - 原神所需的安装空间（约 115GB）
     - 推荐的替代磁盘及其可用空间（可通过 `fsutil volume diskfree` 命令查询各盘空间）
  3. **提示用户手动操作**：
     - "请在安装路径对话框中点击'更改'按钮，将安装路径修改到空间充足的磁盘（如 D:\），修改完成后回复我，我将继续安装流程。"
  4. **等待用户确认**后：
     - 重新 `exe_capture_window` 截图验证路径已更改且空间充足
     - 继续点击"开始安装..."按钮

**禁止行为**：
- ❌ 不要自行尝试点击"更改"按钮
- ❌ 不要自行尝试在路径输入框中输入新路径
- ❌ 不要在未通知用户的情况下忽略空间不足警告直接点击安装

### 2.3 应用商店搜索/安装失败

- 如果 `search_app` 搜索"原神"/"米哈游启动器"/"HoYoPlay"均无结果
- 或 `manage_app` 安装任务失败（`query_task` 返回失败状态）
- 可尝试重新调用 `manage_app` 重试安装
- 如多次重试无效，回退到手动方案：通过浏览器访问 `https://ys.mihoyo.com/main/` 下载米哈游启动器安装包

### 2.4 已安装原神的情况

- 如果 `name_cue(action="launch", name="米哈游启动器" / "原神" / "HoYoPlay")` 成功启动，且启动器中原神按钮显示"开始游戏"而非"获取游戏"
- 说明原神已安装，无需重复安装，直接告知用户

### 2.5 窗口焦点丢失/最小化处理

焦点管理见 §1.5。窗口状态判断按通用规范「多显示器」执行。

**窗口找不到（返回错误）的处理**：
- `exe_capture_window` 返回错误（No window found）→ 窗口已关闭或进程已退出
  - 安装程序阶段：安装程序可能已完成并自动关闭 → `name_cue` 重新启动
  - 启动器阶段：启动器可能已崩溃 → `name_cue` 重新启动
