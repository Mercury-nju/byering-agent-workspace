# 腾讯电脑管家 桌面应用操作规范

## 0. 应用概述

**应用类型**：native（原生 Windows 应用）。腾讯电脑管家是原生 Windows 应用，使用标准 Win32/WPF 控件。

**窗口特征**：
- 主窗口为单窗口布局，左侧有垂直导航栏（功能菜单），右侧为功能主区域
- 左侧导航栏包含：首页、病毒查杀、垃圾清理、电脑加速、工具箱等核心功能入口
- 顶部区域通常显示体检评分或安全状态概览
- 窗口标题栏右侧有最小化、关闭按钮，关闭按钮默认行为可能是**最小化到系统托盘**而非退出

⚠️ 腾讯电脑管家关闭窗口时默认最小化到托盘，不会真正退出。如需完全退出，需右键点击系统托盘中的电脑管家图标 → 选择"退出"。

## 0.1 参数规则

**本 App 推荐窗口名**：`app_name="腾讯电脑管家"`（备选 `"电脑管家"`）

**App 特有规则**：
- **`window_x` / `window_y` 窗口状态识别**：如最小化、隐藏、多显示器位置判断。

## 1. 核心操作流程

### 1.1 全面体检

```
打开腾讯电脑管家
  ├─ 确认进入首页（默认页面）
  ├─ 查找"全面体检"按钮（通常为首页中央醒目大按钮）
  ├─ 点击"全面体检"
  ├─ 等待体检进度完成（可能需要 10-30 秒）
  ├─ 体检完成后，读取评分和各项检测结果
  └─ 如有问题项，可点击"一键修复"按钮
```

### 1.2 病毒查杀

```
左侧导航栏 → 点击"病毒查杀"
  ├─ 进入病毒查杀页面
  ├─ 选择扫描方式：
  │   ├─ "快速扫描"（扫描关键区域，速度快）
  │   ├─ "全盘扫描"（扫描所有磁盘，耗时较长）
  │   └─ "自定义扫描"（选择指定目录）
  ├─ 点击对应扫描按钮
  ├─ 等待扫描完成（快速扫描约 1-3 分钟，全盘扫描较久）
  └─ 扫描完成后，查看结果并处理威胁项
```

### 1.3 空间清理（垃圾清理）

⚠️ **【清理原则】** 当用户要求"清理垃圾"、"清理内存"、"空间清理"等操作时，**执行一键清理即可**。其他子功能（C盘清理、软件搬家、软件卸载）为按需操作，除非用户明确要求否则可以跳过。

**进入方式**：首页点击"空间清理"卡片，进入空间清理页面。

空间清理页面**左侧有垂直子导航栏**，包含以下子功能（从上到下）：

| 子功能 | 说明 | 核心操作 |
|-------|------|---------|
| **一键清理** | 综合清理系统垃圾、缓存、临时文件等 | 点击"一键扫描" → 等待扫描完成 → 点击"立即清理"/"一键清理" |
| **C盘清理** | 专门针对C盘空间的深度清理，清理系统更新缓存、大文件等 | 点击"开始扫描"/"扫描" → 等待扫描完成 → 勾选要清理的项目 → 点击清理（此项按需操作，不强制执行） |
| **软件搬家** | 将安装在C盘的软件迁移到其他磁盘以释放C盘空间 | 查看可搬移的软件列表 → 选择目标磁盘 → 执行搬移（此项按需操作，不强制执行） |
| **软件卸载** | 卸载不需要的软件释放空间 | 查看已安装软件列表（此项按需操作，不强制执行） |

**完整清理流程**：

```
首页 → 点击"空间清理"卡片
  │
  ├─ 【第1步：一键清理】（必做）
  │   ├─ 确认左侧导航选中"一键清理"（默认进入项）
  │   ├─ 点击"一键扫描"按钮
  │   ├─ 等待扫描完成（观察进度，可能 10-30 秒）
  │   ├─ 扫描完成后，读取扫描结果（垃圾大小、分类）
  │   ├─ 点击"立即清理"/"一键清理"按钮
  │   ├─ 等待清理完成
  │   ├─ 点击"好的"按钮关闭清理结果页
  │   └─ 读取清理结果，记录清理数据
  │
  ├─ 【第2步：C盘清理】（按需，不强制）
  │   ├─ 点击左侧导航中的"C盘清理"
  │   ├─ 进入C盘清理页面
  │   ├─ 点击"开始扫描"/"扫描"按钮
  │   ├─ 等待扫描完成
  │   ├─ 查看可清理项目列表（系统更新缓存、大文件、重复文件等）
  │   ├─ 默认勾选推荐清理项，点击"立即清理"/"清理"按钮
  │   ├─ 等待清理完成
  │   └─ 读取清理结果，记录清理数据
  │
  ├─ 【第3步：软件搬家】（按需，不强制）
  │   ├─ 点击左侧导航中的"软件搬家"
  │   └─ 查看是否有建议搬移的软件，如用户未特别要求则跳过
  │
  └─ 【第4步：软件卸载】（按需，不强制）
      ├─ 点击左侧导航中的"软件卸载"
      └─ 查看是否有建议卸载的软件，如用户未特别要求则跳过
```

⚠️ **关键提醒**：
- 一键清理是**必做项**，用户要求清理时必须执行
- C盘清理、软件搬家和软件卸载是**可选项**，除非用户明确要求否则可以跳过
- 每个子功能完成后，直接点击左侧导航栏切换到下一个子功能即可，**无需先点击返回按钮**
- 所有清理完成后，可通过左侧导航栏切换到其他功能，或点击标题栏的"<"返回箭头回到首页

### 1.4 电脑加速

```
左侧导航栏 → 点击"电脑加速"
  ├─ 进入电脑加速页面
  ├─ 点击"一键加速"或"全面加速"按钮
  ├─ 等待扫描可优化项
  ├─ 查看可优化的启动项、运行项等
  └─ 点击"立即加速"或勾选目标项后加速
```

### 1.5 软件管理

```
左侧导航栏 → 点击"软件管理"或"工具箱" → 找到"软件管理"
  ├─ 可能会打开独立的软件管理窗口
  ├─ 顶部有搜索栏用于查找软件
  ├─ 支持"软件安装"、"软件卸载"、"软件升级"等标签页
  └─ 选择对应标签页后操作
```

### 1.6 注意事项

- 体检、扫描等操作有进度条，需等待完成后再进行下一步操作
- 部分操作（如清理系统垃圾）可能需要**管理员权限**，触发 UAC 弹窗时需通知用户接管
- 病毒查杀全盘扫描耗时较长，建议优先使用快速扫描

### 3.1 点击失败后的坐标校准策略

🔴 **【核心规则】** 当点击操作未达到预期效果（界面无变化），**必须执行以下校准流程**，禁止盲目重复使用相同坐标重试。
通用「点击失败反思」流程作为基线，以下为本 App 特有补充。

**校准流程（鼠标光标反推法）**：

```
点击后截图发现界面无变化
  │
  ├─ 【优先：尝试 exe_dump_ui 重新定位】
  │   ├─ 调用 exe_dump_ui("腾讯电脑管家") 获取当前窗口所有文字元素及坐标
  │   ├─ 在返回结果中查找目标按钮文字（如"全面体检"、"一键清理"等）
  │   ├─ 如果找到，使用返回的中心坐标 + 窗口偏移重新点击
  │   └─ 如果未找到目标文字（可能是纯图标按钮），继续以下截图校准流程
  │
  ├─ 【步骤1：获取鼠标当前位置】
  │   ├─ 调用 `exe_get_mouse_pos` 获取鼠标当前的屏幕绝对坐标 (cursor_x, cursor_y)
  │   └─ 该坐标即为上次点击实际落点的物理像素位置
  │
  ├─ 【步骤2：截图确认光标位置】
  │   ├─ 调用 `exe_capture_window` 截图
  │   ├─ 调用`gui_grounder`, 在截图中找到鼠标光标的实际位置（光标通常表现为箭头图标）
  │   └─ 确认光标相对于目标按钮的偏移方向和距离
  │
  └─ 【步骤3：使用修正坐标重新点击】
      ├─ 用修正后的屏幕坐标执行点击
      └─ 点击后再次截图验证是否成功
```

⚠️ **关键提醒**：
- **反推法比直接用截图元数据中的 window_x/window_y 更准确**，因为窗口可能被用户拖动、或存在标题栏/边框的偏差
- 校准后如仍失败，可再次执行校准流程；连续 3 次失败则告知用户

## 4. 特殊场景处理

### 4.1 启动时弹窗/广告

按通用规范「中断处理 > AI 自动恢复型」执行。腾讯电脑管家特有：
- **关闭行为差异**：点击窗口关闭按钮（×）默认最小化到系统托盘，不会退出程序。

### 4.2 UAC 权限弹窗

安装清理系统垃圾等操作可能触发 UAC，参见通用规范「中断处理 > 用户接管型」。

### 4.4 扫描超时处理

- 全盘扫描或深度体检可能耗时较长（5-30 分钟）
- 每隔 10-15 秒截图检查进度状态
- 如发现扫描卡住不动（连续多次截图进度无变化），可尝试点击"暂停"后"继续"
- 如仍无响应，告知用户

### 4.5 软件管理独立窗口

点击"软件管理"可能打开独立窗口，此时需注意：
- 主窗口和软件管理窗口可能同时存在
- 操作完成后可能需要关闭软件管理窗口回到主窗口
