# Steam 桌面应用操作规范

## 0. 应用概述

**应用类型**：native（原生 Windows 应用）
**推荐窗口名**：`app_name="Steam"`

**窗口特征**：
- 主窗口顶部有导航栏（商店、库、社区等）；关闭窗口（×）默认**最小化到系统托盘**而非退出。
- 完全退出需右键系统托盘图标 → "退出 Steam"。

## 1. 操作路由（每次操作前必须先执行此决策）

**这是本文档最高优先级的规则。无论用户请求什么 Steam 操作，必须先按下方流程判断工具选择，禁止跳过此步骤直接执行视觉操作。**

决策流程如下：

```
收到用户关于 Steam 的操作请求
  │
  ├─ Step 1: 判断操作类型，匹配专属工具
  │
  │   ┌─ 搜索游戏 ──────────────→ steam_search_game
  │   ├─ 检查安装状态 ──────────→ steam_game(steam_act="check")
  │   ├─ 安装/下载游戏 ─────────→ steam_game(steam_act="install")
  │   ├─ 卸载游戏 ─────────────→ steam_game(steam_act="uninstall")
  │   ├─ 启动游戏 ─────────────→ steam_game(steam_act="launch")
  │   └─ 其他（浏览/好友/设置）─→ smart-desktop-ops 通用视觉操作
  │
  ├─ Step 2: 匹配到专属工具时，直接使用；获取 steam_app_id 方式：先 steam_search_game 搜索，从结果中提取
  │
  └─ Step 3: 仅当专属工具返回错误或超时，才允许回退到视觉操作
```

## 2. 核心操作流程

> 以下所有流程均已按 §1 路由规则使用专属工具，执行时直接遵循即可。

### 2.1 搜索并下载游戏

```
用户请求"在Steam下载Bongo Cat游戏"
  │
  ├─ 搜索游戏
  │   ├─ steam_search_game({query: "Bongo Cat"})
  │   └─ 从结果中提取 steam_app_id
  │
  ├─ 检查安装状态
  │   ├─ steam_game(steam_act="check", steam_app_id="...")
  │   ├─ 已安装 → 告知用户，询问是否启动
  │   └─ 未安装 → 继续
  │
  ├─ 触发安装
  │   ├─ steam_game(steam_act="install", steam_app_id="...")
  │   └─ Steam 弹出安装确认对话框
  │
  ├─ 确认安装（视觉操作）
  │   ├─ exe_focus_window(app_name="Steam") 让确认窗口前置
  │   ├─ exe_capture_window(app_name="Steam") 获取当前界面
  │   ├─ 优先用 exe_dump_ui(app_name="Steam") 查找"安装"/"下一步"/"完成"按钮
  │   ├─ 如 OCR 命中 → 用 source="ocr" + app_name="Steam" 执行点击
  │   ├─ 如 OCR 未命中 → 退回窗口截图 + `gui_grounder` 获取精确坐标，用 source="window" + app_name="Steam" 执行点击
  │   └─ 再次截图确认安装已进入下载队列
  │
  └─ 【完成】汇报操作结果
```

⚠️ **安装确认规则**：调用 `steam_game(steam_act="install")` 后，**必须继续通过截图/OCR 完成安装确认**，不得停留在对话框等待用户操作。

### 2.2 启动已安装的游戏

```
用户请求"启动某游戏"
  │
  ├─ 调用 steam_game(steam_act="check", steam_app_id="...") 检查安装状态
  ├─ 如已安装 → 调用 steam_game(steam_act="launch", steam_app_id="...") 启动
  └─ 如未安装 → 告知用户并询问是否安装
```

### 2.3 卸载游戏

```
用户请求"卸载某游戏"
  │
  ├─ 【第1步：检查安装状态】
  │   ├─ 调用 steam_game(steam_act="check", steam_app_id="...") 确认游戏存在
  │   └─ 如未安装 → 告知用户"游戏未安装，无需卸载"并结束
  │
  ├─ 触发卸载
  │   ├─ steam_game(steam_act="uninstall", steam_app_id="...") 执行卸载
  │   └─ Steam 弹出卸载确认对话框
  │
  ├─ 确认卸载（视觉操作）
  │   ├─ exe_focus_window(app_name="Steam") 让确认窗口前置
  │   ├─ exe_capture_window(app_name="Steam") 获取当前界面
  │   ├─ 优先用 exe_dump_ui(app_name="Steam") 查找"卸载"/"确定"/"删除"按钮
  │   ├─ 如 OCR 命中 → 用 source="ocr" + app_name="Steam" 执行点击
  │   ├─ 如 OCR 未命中 → 退回窗口截图 + `gui_grounder` 获取精确坐标，用 source="window" + app_name="Steam" 执行点击
  │   └─ 再次截图确认卸载完成
  │
  └─ 【完成】汇报操作结果
```

⚠️ **卸载确认规则**：调用 `steam_game(steam_act="uninstall", steam_app_id="...")` 后，**必须继续通过截图/OCR 完成卸载确认**，不得停留在确认对话框等待用户操作。

### 2.4 浏览商店页面（通用视觉操作）

以下操作无专属工具，使用 smart-desktop-ops 通用方式。

```
打开 Steam（如未运行）
  ├─ 等待 5-8 秒（Steam 启动较慢）
  │
浏览商店
  ├─ 点击顶部导航栏"商店"标签页
  ├─ 识别热门游戏、特惠游戏等板块
  └─ 读取页面内容并汇报给用户
```

## 3. 界面元素定位提示

以下描述元素的视觉特征和典型位置，定位方式按通用规范「界面感知与坐标」执行。

| 目标元素 | 视觉特征 | 典型位置 |
|---------|---------|---------|
| 顶部导航栏 | 包含"商店""库""社区"等标签页文字，深色背景 | 窗口顶部，横向排列 |
| 商店标签 | 文字"商店"或"STORE" | 顶部导航栏左侧 |
| 库标签 | 文字"库"或"LIBRARY" | 顶部导航栏，商店右侧 |
| 搜索框 | 带放大镜图标的输入框 | 商店页面顶部或右上角 |
| 游戏列表（库） | 垂直列表，显示游戏封面和名称 | 库页面左侧边栏 |
| 安装/游玩按钮 | 绿色醒目按钮，文字"安装""游玩""免费开玩" | 游戏详情页右侧或中部 |
| 下载进度 | 进度条 + 百分比 + 下载速度 | 库页面底部或下载管理页面 |
| 系统托盘图标 | Steam 标志性图标（黑色圆圈内白色 S 形） | Windows 任务栏右侧系统托盘 |
| 关闭/最小化按钮 | 窗口右上角 × 和 - 按钮 | 窗口标题栏最右侧 |

## 4. 特殊场景处理

### 5.1 启动时弹窗

按通用规范「中断处理 > AI 自动恢复型」执行。

### 5.2 登录状态

- Steam 通常保持登录状态
- 如果检测到登录界面（有用户名/密码输入框），参见通用规范「中断处理 > 用户接管型」
- 涉及敏感操作（如购买游戏需要输入支付密码）时，也需用户接管

### 5.3 游戏安装路径选择

- 使用 `steam_game(steam_act="install", steam_app_id="...")` 时，默认使用 Steam 配置的默认安装路径
- 如果用户需要指定安装路径，需通过通用视觉操作在安装确认弹窗中选择

### 5.4 下载队列管理

- 安装游戏后，可以在"库"页面底部或"下载"页面查看下载进度
- 大型游戏下载时间较长，告知用户预估时间（如有显示）

### 5.5 关闭行为

⚠️ 点击窗口关闭按钮（×）默认最小化到系统托盘，不会退出程序（已在 §0 说明）。

- **仅关闭窗口**：直接点击 × 或 `alt+f4`（Steam 仍在后台运行）
- **完全退出**：需右键系统托盘中的 Steam 图标 → 点击"退出 Steam"
