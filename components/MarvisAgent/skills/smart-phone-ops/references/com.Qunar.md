# 去哪儿旅行 App 操作规范

**类型**：普通 App（dump_ui 优先）

## 0. 核心特性

- ⚠️ **【结果展示规则】** 查询到的机票/酒店/火车票等信息必须以 **Markdown 表格** 形式呈现给用户，包含关键信息。
- ⚠️ **【购买确认规则】** 展示结果表格后，必须等待用户确认选择后，才能进行后续购买操作。**禁止未经用户确认就自动下单。**
- ⚠️ **【采集条数覆盖】** 机票信息至少采集 **5 条以上**，尽量覆盖不同时段、不同航空公司。

## 0.1 URL Scheme 快速导航

| 场景 | Scheme |
|------|--------|
| App 首页 | `qunaraphone://home` |
| 机票首页 | `qunaraphone://flight/main` |
| 酒店首页 | `qunaraphone://hotel/main` |
| 火车票首页 | `qunaraphone://railway/main` |
| 汽车票首页 | `qunaraphone://bus/main` |
| 门票首页 | `qunaraphone://sight/main` |

> 调用方式：`operate_app(operate_type="launch", package_names=["com.Qunar"], apk_deep_link="<scheme>")`

## 2. 机票查询流程

### 2.1 进入机票页面

```
用户提出机票需求（如"帮我查深圳到上海的机票"）
  │
  ├─ 方式 A（⭐ 推荐）：通过 Scheme 直达机票首页
  │   └─ operate_app(operate_type="launch", package_names=["com.Qunar"],
  │        apk_deep_link="qunaraphone://flight/main")
  │   └─ dump_ui 确认已进入机票搜索页
  │   └─ 继续 2.2 设置城市 + 2.3 设置日期
  │
  └─ 方式 B（兜底）：Scheme 失败时
      ├─ operate_app(operate_type="launch", package_names=["com.Qunar"])
      ├─ dump_ui 检查弹窗，有则关闭
      └─ 在首页点击「机票」入口
```

**方式 B — 定位「机票」按钮的策略（按优先级）**：

1. **dump_ui 方式（最精确）**：
   - 在控件树中搜索 `text` 包含"机票"的可点击节点
   - 注意区分"机票"入口按钮和页面中其他含"机票"文字的元素（如推荐卡片）
   - 功能入口按钮通常在页面上半部分，且是独立的可点击控件

2. **截图 + `gui_grounder` 方式（备选）**：
   - 调用 `gui_grounder` 工具进行定位，务必清晰描述目标元素
   - 如果误触广告，使用 `tap_back` 返回后重新定位

3. **搜索栏快捷方式（兜底策略）**：
   - 如果多次点击「机票」按钮失败，可以尝试：
     - 点击首页搜索栏
     - 输入"深圳到上海机票"进行搜索
     - 通过搜索结果进入机票查询页面

### 2.2 设置出发地和目的地

```
机票查询页面结构:
  ├─ 出发城市（左侧）
  ├─ 交换按钮（中间的双向箭头 ⇌）
  ├─ 到达城市（右侧）
  ├─ 出发日期
  ├─ 返回日期（可选）
  ├─ 舱位选择（经济舱/商务舱等）
  └─ 搜索按钮
```

**设置城市操作流程**：

1. 使用 dump_ui / capture_screen 查看当前出发城市和到达城市
2. 如果出发城市不是目标城市：
   - 点击出发城市区域
   - 在城市选择页面中：
     - 优先使用 dump_ui 查找目标城市直接点击
     - 或点击搜索框，输入城市名（如"深圳"），从搜索结果中选择
3. 同理设置到达城市

**城市输入技巧**：
- 点击城市选择区域后，通常会弹出城市列表页面
- 页面顶部有搜索框，可以输入城市名快速定位
- 输入后从联想/搜索结果中点击选择目标城市
- ⚠️ 输入前先用 `input_text_at` 清除已有文本（该工具自带清空功能）

### 2.3 设置出发日期

1. 点击日期选择区域
2. 日历面板通常显示当月和下月
3. 如果目标日期不在当前视图中，swipe 向左/上滑动翻到下个月
4. 点击目标日期

**日期定位策略**：
- dump_ui：查找包含目标日期数字的节点，通过 text 或 content-desc 匹配
- 截图：在日历面板中视觉定位目标日期并计算坐标

### 2.4 点击搜索

设置好出发地、目的地、日期后：

1. 使用 dump_ui / capture_screen 确认所有信息填写正确
2. 定位"搜索"/"查询"按钮并点击
3. 等待搜索结果加载

### 2.5 采集机票信息

搜索结果页面通常显示航班列表，每个航班卡片包含：

| 信息项 | 说明 |
|--------|------|
| 航空公司 | 如南方航空、东方航空等 |
| 航班号 | 如 CZ3001 |
| 出发时间 | 如 08:00 |
| 到达时间 | 如 10:30 |
| 飞行时长 | 如 2h30m |
| 出发/到达机场 | 如 深圳宝安T3 → 上海虹桥T2 |
| 价格 | 如 ¥680 |
| 舱位折扣 | 如 经济舱4.5折 |

**信息采集流程**：

```
搜索结果页
  │
  ├─ 步骤1. dump_ui / capture_screen 查看结果列表
  │         获取当前屏幕可见的航班信息
  │
  ├─ 步骤2. 记录当前屏幕可见的所有航班信息
  │
  ├─ 步骤3. swipe 向上滑动，加载更多航班
  │         继续采集更多航班信息
  │
  ├─ 步骤4. 重复步骤2-3，采集 5~10 条航班信息
  │
  └─ 步骤5. 整理为表格格式
```

⚠️ **重要**：
- 如果 dump_ui 能获取到列表数据，优先从控件树中提取文本信息（更精确）
- 如果第一屏不够 5 条，需要 swipe 向上滑动查看更多

### 2.6 展示结果（Markdown 表格）

将采集到的航班信息整理成 **Markdown 表格**，格式如下：

```markdown
| 序号 | 航空公司 | 航班号 | 出发时间 | 到达时间 | 出发机场 | 到达机场 | 价格 | 备注 |
|------|----------|--------|----------|----------|----------|----------|------|------|
| 1 | 南方航空 | CZ3001 | 08:00 | 10:30 | 深圳宝安T3 | 上海虹桥T2 | ¥680 | 经济舱4.5折 |
| 2 | 东方航空 | MU5302 | 09:15 | 11:45 | 深圳宝安T3 | 上海浦东T1 | ¥720 | 经济舱5折 |
| ... | ... | ... | ... | ... | ... | ... | ... | ... |
```

展示表格后，**必须询问用户**：
> "以上是查询到的航班信息，请问您想预订哪一个航班？请回复序号。"

### 2.7 用户确认后执行购买

⚠️ **必须等待用户明确回复选择的航班序号后，才能继续操作。**

用户确认后：

1. 在搜索结果页面定位用户选择的航班
2. 如果需要滑动到该航班，使用 swipe 操作
3. 点击该航班卡片，进入航班详情/订单页面
4. 在订单页面中：
   - 确认航班信息与用户选择一致
   - 查看是否需要填写乘客信息
   - 查看总价（含税费、保险等）
5. **再次将订单详情告知用户确认**，包括：
   - 最终价格（含附加费用）
   - 出行人信息是否需要填写
   - 是否有附加服务（保险、接送机等）需要取消勾选
6. 用户确认无误后，按用户指示完成后续步骤

## 3. App 特有弹窗

> 通用弹窗处理按通用规范 §1.2 执行。以下为去哪儿特有的弹窗类型：

| 弹窗类型 | 特征 | 处理 |
|---------|------|------|
| 启动广告 | 带倒计时的全屏/半屏广告 | 等待倒计时结束或点击"跳过"按钮 |
| 低价提醒 | 弹出低价提醒通知 | 查找"关闭"或 X 按钮 |
| 城市/日期已默认正确 | 进入机票页面后默认值已符合需求 | 无需重复设置，直接搜索 |

## 4. 界面元素定位提示

| 目标元素 | 定位方式 |
|---------|---------|
| 机票入口 | dump_ui 查找 text 包含"机票"的可点击节点（页面上半部分，独立的可点击控件） |
| 出发/到达城市 | 机票查询页面左右两侧城市区域，点击弹出城市列表 |
| 城市交换按钮 | 出发地和目的地之间的双向箭头 ⇌ |
| 日历面板 | 日期选择区域，swipe 翻月，点击目标日期 |
| 搜索按钮 | 机票查询页面底部，text 含"搜索"/"查询" |
| 航班卡片 | 搜索结果页的可点击列表项 |
