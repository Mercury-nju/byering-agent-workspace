# TapTap游戏平台操作规范

**类型**：普通 App（dump_ui 优先）

## 操作流程

- 搜索游戏
  - 查找搜索框（resource-id含"search"且clickable=true）
  - 点击搜索框聚焦
  - 输入游戏名称
  - 查找并点击"搜索"按钮
  - dump_ui分析搜索结果列表
- 查看游戏详情
  - 在列表中找到目标游戏卡片
  - 点击进入详情页
  - dump_ui分析游戏基本信息区域
  - 查看评分、下载量等关键数据

## 界面元素定位

| 目标元素 | dump_ui搜索策略 | 备用方案 |
|----------|-----------------|----------|
| 搜索框 | 查找resource-id含"search"且clickable=true | 截图找放大镜图标 |
| 游戏卡片 | 查找包含游戏标题文本的RelativeLayout | 截图观察后使用`gui_grounder`定位目标游戏 |
| 下载按钮 | 查找text="下载"或"安装"且clickable=true | 绿色按钮识别 |
| 分类Tab | 查找包含"首页""排行榜"等文字的TextView | 顶部横向排列按钮 |
| 返回按钮 | 查找content-desc="返回"或系统返回键 | 左上角箭头图标 |

## 结果输出格式

查询游戏信息时按此格式汇报：

```markdown
**游戏基本信息**
- 名称:
- 评分:
- 大小:
- 最新版本:
- 开发商:

**下载状态**
- 当前状态: [未下载/已下载/已安装/更新中]
- 按钮文字:

**用户评价摘要**
- 好评率:
- 评价总数:
```
