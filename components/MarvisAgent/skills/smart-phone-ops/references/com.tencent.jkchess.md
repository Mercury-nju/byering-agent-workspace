# 金铲铲之战 App 操作规范

**类型**：游戏 App，统一使用 `capture_screen` 截图 + `gui_grounder` 定位

## 核心特性

- **弹窗关闭**：游戏内 X 按钮点击区域极小（约 30px），**禁止直接点 X 关闭弹窗**。关闭尝试顺序：① tap_back → ② 点击弹窗外遮罩区域 → ③ 最后才试 X（最多 1 次）。

- **签到/领奖范围红线**：
  - **唯一入口是「事件」**，主界面其他按钮均与签到/领奖无关
  - 遍历完事件弹窗所有 Tab 后，tap_back 关闭 → 直接输出结果 → **任务结束**
  - 🚫 禁止再点击主界面任何其他按钮（福利、特权、商城、宝库、召唤、邮件、月卡、特惠、首充等）
  - 🚫 禁止"回到主界面检查是否还有其他签到入口"——不存在其他入口

## 签到与领取流程

```
启动游戏后
  │
  ├─ capture_screen 检查
  │     ├─ 有「开始游戏」→ gui_grounder 定位 → 点击进入
  │     │     （禁止手动选服，使用默认服务器；误入选服页立即 tap_back）
  │     ├─ 有公告/更新弹窗 → tap_back 关闭（禁止点 X）
  │     └─ 已在主界面 → 继续
  │
  ├─ capture_screen 确认主界面
  │
  ├─ gui_grounder 定位左侧边栏「事件」按钮 → 点击进入
  │
  ├─ 遍历事件弹窗所有 Tab（见下方规范）
  │
  ├─ 全部 Tab 遍历完毕 → tap_back 关闭事件弹窗（禁止点 X）
  │
  └─ 直接输出结果，任务结束
```

## 事件弹窗 Tab 遍历规范

```
进入事件弹窗
  │
  ├─ 1. capture_screen 获取弹窗全貌，识别所有 Tab
  │
  ├─ 2. 按优先级处理：
  │     ├─ 🔴 有红点/角标的 Tab → 优先处理
  │     ├─ 📋 含"签到""任务""登录""每日"关键词 → 次优先
  │     └─ 💰 含"超值""优惠""返利""福星卡"等付费关键词 → 快速浏览，无免费奖励则跳过
  │
  ├─ 3. 对每个 Tab：gui_grounder 定位 → 点击 → capture_screen 查看
  │     ├─ 有免费领取按钮（「领取」「签到」「一键领取」）→ 点击领取
  │     └─ 纯付费内容 → 跳过
  │
  └─ 4. 全部处理完 → tap_back 关闭弹窗
```

> ⚠️ 点击 Tab 后可能需要加载时间，等待后再截图。Tab 列表较长时可在 Tab 区域 swipe 查看更多。

## 结果输出格式

```markdown
### 金铲铲之战签到结果

- **签到状态**：✅ 已完成 / ❌ 失败
- **活动 Tab 遍历**：共 N 个 Tab，已全部点击查看
- **领取的奖励**：
  - [Tab名称1]：领取了 xxx 奖励
  - [Tab名称2]：无可领取内容
- **备注**：[其他需要说明的情况]
```
