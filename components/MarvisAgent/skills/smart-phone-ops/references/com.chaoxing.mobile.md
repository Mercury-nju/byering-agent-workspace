# 学习通 App 操作规范

**类型**：普通 App（dump_ui 优先）

## 0. 核心特性

> 学习通是普通 App，按通用规范 §4.1 执行界面感知（dump_ui 优先）。

- **内容类型**：视频（知视频板块）、课程、图书等，本 skill 以**视频搜索与分析**为核心场景
- **跨App协作**：报告生成后需切换至 Flomo（`com.flomo.app`）保存
- **浏览模式**：支持免登录浏览公开内容，优先使用浏览模式避免登录流程

## 1. 启动后弹窗处理

```
启动学习通后
  │
  ├─ 1. 处理弹窗（隐私→点"同意"、登录→点"浏览"/"先逛逛"、广告→点"关闭"/"取消"）
  │
  └─ 2. 确认进入首页
```

> ⚠️ 搜索公开视频时，**优先进入浏览模式**，避免登录流程。

## 2. 搜索流程（⭐最快路径：首页直达知视频搜索）

> ⚠️ **不走首页顶部搜索框**（首页搜索默认非视频结果，还需切Tab，多一步）。直接从首页进入「知视频」板块，用板块内搜索框搜索，一步到位。

### 2.1 进入知视频板块

```
从首页直达知视频：
  │
  ├─ 1. 在首页找到"知视频"入口
  │     └─ 使用dump_ui或者截图+ `gui_grounder`，查找 text="知视频" 的可点击控件
  │     └─ 通常位于首页功能区域（应用中心/推荐位/底部Tab）
  │     └─ android_tap 点击进入知视频板块
  │
  └─ 2. 确认已进入知视频页面
        └─ capture_screen 确认页面标题含"知视频"或显示视频列表
```

### 2.2 搜索框激活与搜索（知视频内搜索 ⭐）

> ⚠️ 知视频板块的搜索框同为 **WebView 元素**，激活方式与首页相同：点击**左 1/3 处**。

```
在知视频板块内搜索：
  │
  ├─ 1. dump_ui 查找搜索框（EditText 或 text 含"搜索"）
  │     └─ 记录 bounds: [left, top, right, bottom]
  │     └─ X = left + (right - left) / 3    ← 左1/3处（非中间！）
  │     └─ Y = (top + bottom) / 2
  │
  ├─ 2. android_tap(X, Y) 激活搜索框
  │
  ├─ 3. 输入关键词并触发搜索
  │     └─ input_text_at("{关键词}{换行符}")   ← 输入搜索关键词，和换行符。
  │
  └─ 4. capture_screen 确认搜索结果已加载
        └─ ⚠️ 知视频内搜索结果直接就是视频，无需再切Tab
```

⚠️ 学习通搜索框是「非即时筛选」类型，输入后**不会自动显示结果**，必须包含换行符来主动触发搜索。

## 3. 视频详情页操作规范

### 3.1 视频选择策略（选择"最新"视频）

```
从搜索结果中选择最新视频：
  ├─ 优先依据：发布时间（越新越好）> 播放量 > 排序位置
  ├─ 时间识别：详情页发布日期 / 标题中年份 / 列表时间标注
  └─ 如无法从列表判断时间，进入第1条视频详情页确认
```

### 3.2 视频信息采集流程（⭐先看视频内容，再收集元数据）

> ⚠️ **优先观看视频内容**，因为视频画面是核心分析素材。观看后再向下滚动收集页面其他信息。

```
点击视频进入详情页
  │
  ├─ 1. 优先播放并观看视频内容 ⭐
  │     ├─ capture_screen 获取首屏，使用`gui_grounder`定位上方播放按钮，并执行android_tap操作。
  │     ├─ 每隔10-15秒 capture_screen 截取关键帧（至少3-5帧）
  │     ├─ 关注画面中的文字、图表、PPT内容
  │     ├─ 长视频(>3分钟)重点截取：开头→中段→结尾
  │     └─ android_tap 暂停视频
  │
  ├─ 2. swipe 向下收集描述/简介、元数据（标题/作者/时间/时长）
  │
  ├─ 3. 获取互动数据（播放量/点赞/收藏/分享/评论）
  │
  ├─ 4. 继续 swipe 查看评论区（如有），采集热门评论
  │
  └─ 5. tap_back 返回搜索结果
```

### 3.3 注意事项

1. ⚠️ 知视频详情页布局：上方视频播放器 → 中间标题/作者/互动数据 → 下方评论区。需多次 swipe 查看完整内容。评论区在最底部。
2. 使用`gui_grounder`定位播放按钮时，必须说明定位上方播放器中心三角符号的播放按钮
3. 如果上方视频播放器显示为黑屏，说明视频播放按钮处于隐藏状态，需要连续快速点击黑屏播放器正中心位置两次（连续调用两次点击）进行播放；

## 4. 报告生成规范

### 4.1 视频分析报告模板

```markdown
# AI视频分析报告

## 视频基本信息
| 项目 | 内容 |
|------|------|
| **视频标题** | XXX |
| **作者** | XXX |
| **发布时间** | XXXX年X月X日 |
| **视频时长** | X分X秒 |
| **播放量** | X次 |
| **点赞/收藏/分享/评论** | X / X / X / X |

## 视频内容分析
（核心主题2-3句 + 3个视频亮点 + 价值/趋势/社会反响三维度分析）

## 总结与建议
（视频价值 + 3条学习建议 + 拓展资源推荐）

---
**报告生成时间**：YYYY-MM-DD | **数据来源**：学习通App - 知视频
```

## 5. 跨 App 协作：保存至 Flomo

报告生成后如需保存至 Flomo（`com.flomo.app`），切换到 Flomo 专属 skill 执行保存操作。

## 6. 界面元素定位提示

| 目标元素 | 定位方式 |
|---------|---------|
| 知视频入口 | dump_ui 查找 text="知视频" 的可点击控件（首页功能区） |
| 搜索框（知视频内） | dump_ui 查找 EditText 或 text 含"搜索"；**点击左1/3处激活**（WebView特殊处理） |
| 视频条目 | dump_ui 查找包含视频标题的可点击容器（clickable=true） |
| 视频播放器 | 详情页顶部区域，通常占据上半屏；查找播放按钮并 android_tap 播放 |
| 互动数据区 | 视频播放器下方，包含播放量/点赞/收藏/分享/评论等 |
| 评论区域 | 详情页底部区域，需多次 swipe 到达 |
| 隐私弹窗同意按钮 | dump_ui 查找 text 含"同意" 且 clickable=true |
| 浏览模式入口 | dump_ui 查找 text 含"浏览"/"先逛逛"/"游客"的 clickable 节点 |

## 7. 结果输出格式

搜索到视频后按此格式汇报：`🥇 推荐（最新）：《视频标题》 作者：XXX | 发布时间：XXXX-XX-XX | 播放量：X次`，询问用户是否详细分析。完整报告按第4章模板生成，如需保存至 Flomo 按 §5 切换到 Flomo 专属 skill 执行。
