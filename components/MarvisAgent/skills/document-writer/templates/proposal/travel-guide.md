# 旅游攻略/摄影攻略模板

## 章节结构

### 第1章 攻略概览
- **写作要点指导**：概述目的地/主题的核心亮点，使用表格呈现攻略基本信息（目的地、推荐时间、行程天数、预算范围、适合人群），给出整体推荐评级与一句话推荐理由

### 第2章 行前准备
- **写作要点指导**：签证/证件要求（如适用），交通方式与到达方案（机票/高铁/自驾等），住宿推荐（按预算分级：经济/舒适/高端），必带装备与物品清单（含摄影器材，如为摄影攻略），最佳出行季节与天气注意事项

### 第3章 行程规划
- **写作要点指导**：按天编排详细行程（Day 1 / Day 2 / ...），每天包含：景点/活动安排、时间分配建议、交通衔接方式，使用表格呈现每日行程时间表，标注必去景点与可选景点，说明行程的弹性空间与调整建议

### 第4章 景点/体验推荐
- **写作要点指导**：逐一介绍推荐的景点/体验项目，每个景点包含：推荐理由、开放时间、门票价格、游玩时长建议、实用贴士，标注每个景点的推荐指数（⭐⭐⭐⭐⭐），摄影攻略需标注最佳拍摄时间、机位、参数建议

### 第5章 美食推荐
- **写作要点指导**：推荐当地特色美食与餐厅，每个推荐包含：餐厅名/美食名、推荐理由、人均消费、位置/交通，按类型分组（早餐/正餐/小吃/甜品等），标注必吃清单

### 第6章 预算参考
- **写作要点指导**：使用表格列出各项费用估算（交通、住宿、餐饮、门票、购物等），给出总预算范围（经济版/舒适版），标注省钱技巧与注意事项

### 第7章 实用贴士
- **写作要点指导**：安全注意事项，当地风俗与禁忌，通讯/网络/充电等实用信息，常见问题与解决方案（如语言不通、迷路等），紧急联系方式

## 写作要求
- 语言风格：轻松实用、信息密度高，兼具趣味性与实用性
- 数据要求：价格标注货币单位与参考时间（"2024 年参考价"）；时间信息需注明淡旺季差异；距离标注大致交通时间
- 特殊约束：信息时效性很重要，需提示读者核实最新信息；推荐需客观（非广告），优缺点并述；行程安排要考虑实际交通时间与体力分配
