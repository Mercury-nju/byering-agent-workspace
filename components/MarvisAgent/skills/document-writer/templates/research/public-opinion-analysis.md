# 舆情分析报告模板

## 章节结构

### 第1章 舆情概览
- **写作要点指导**：概述监测周期与监测范围，列出核心舆情指标（总声量、情感比例、热度趋势），标注关键舆情事件与风险等级，给出当前舆情态势的整体评价

### 第2章 监测背景与范围
- **写作要点指导**：说明监测的触发原因（日常监测、危机事件、产品发布等），明确监测关键词、平台范围与时间窗口，介绍数据来源与采集方法，说明情感分类标准（正面/中性/负面的判定规则）

### 第3章 声量与趋势分析
- **写作要点指导**：展示监测周期内的声量变化趋势（日/周维度），标注声量峰值对应的触发事件，按平台/渠道拆解声量分布（微博、微信、抖音、新闻、论坛等），分析声量的地域分布（如有）

### 第4章 情感分析
- **写作要点指导**：呈现正面/中性/负面的比例分布，分析各情感倾向的主要话题与典型言论，追踪情感走势的变化拐点，对比不同平台的情感差异

### 第5章 热点话题与传播分析
- **写作要点指导**：提取 Top N 热点话题/关键词，分析核心话题的传播链路（首发→扩散→峰值→衰退），识别关键传播节点（KOL、媒体、社群），分析话题演化路径（议题如何转向）

### 第6章 风险预警
- **写作要点指导**：识别当前存在的舆情风险点，评估风险等级（高/中/低）与潜在影响范围，分析风险的演化趋势（是否在升级），列出需要重点关注的敏感话题/人物/平台

### 第7章 应对策略与建议
- **写作要点指导**：针对不同风险等级给出差异化应对策略，提出正面舆论的引导与放大方案，制定负面舆情的化解与回应方案，给出长期舆情管理建议（监测机制、预案体系）

### 附录
- **写作要点指导**：典型言论摘录、关键传播节点列表、监测平台与工具说明

## 写作要求
- 语言风格：正式、客观中立，紧迫感与专业性并重
- 数据要求：声量数据标注来源平台与采集时间；情感分析需说明判定方法；传播数据需标注统计口径
- 特殊约束：时效性是舆情分析的生命线，数据截止时间必须明确标注；引用原始言论时需注明来源平台与时间；应对策略必须分等级分场景，不能一刀切
