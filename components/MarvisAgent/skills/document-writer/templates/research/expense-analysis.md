# 费用分析报告模板

## 章节结构

### 第1章 核心摘要
- **写作要点指导**：概述费用分析的关键发现（总支出、预算执行率、同比变化），列出费用异常项与风险点，给出最核心的控费建议

### 第2章 费用总览
- **写作要点指导**：呈现分析周期内的费用总额及同比/环比变化，使用表格展示各费用大类的金额与占比，对比预算总额与实际执行率，标注超支/节余项

### 第3章 费用结构分析
- **写作要点指导**：按费用类型拆解（人力成本、差旅费、办公费、营销费、外包费等），分析各类费用的占比及变化趋势，按部门/项目/成本中心进一步细分，识别占比异常增长或下降的科目

### 第4章 趋势对比分析
- **写作要点指导**：展示费用的月度/季度变化趋势，进行同比（vs 去年同期）与环比（vs 上期）分析，识别季节性规律或周期性波动，分析费用变化的关键驱动因素

### 第5章 异常分析
- **写作要点指导**：列出超出预算阈值的费用科目，分析异常的原因（业务增长、一次性支出、管理问题等），评估异常费用的合理性与影响程度，区分一次性异常与结构性问题

### 第6章 控费建议
- **写作要点指导**：针对各费用科目给出具体的优化措施（如差旅标准优化、外包比价机制等），区分短期节约行动与中长期成本优化策略，估算建议措施的预期节约金额，给出下期预算调整建议

### 附录
- **写作要点指导**：费用数据明细表、预算对比表、数据来源说明

## 撰写原则

1. **数据驱动**：所有结论必须有费用数据支撑，禁止主观臆断
2. **全面覆盖**：**必须分析数据中出现的所有费用科目/类型**，不得遗漏。如数据包含 N 个费用科目，报告必须覆盖全部 N 个科目
3. **不编造数据**：报告中出现的所有数值必须来源于原始数据，**绝对禁止凭常识或假设编造**。如果原始数据中没有提供预算值，**必须省略预算列或标注"未提供"**
4. **异常聚焦**：在全面覆盖基础上重点分析异常项，区分一次性异常与结构性问题
5. **建议可执行**：每条控费建议必须关联具体费用科目，并附预期节约效果

### 建议撰写标准

- ❌ "需要控制差旅费用" → 太笼统
- ✅ "差旅费同比增长 35.2%（从 180 万增至 243 万），其中国际差旅占增量的 72%，建议：① 国际出差改为视频会议优先审批制；② 提前 14 天预订享受折扣票价；预计年度节约 40-50 万" → 有数据、有归因、有方案、有预期

## 质量检查清单

> ⚠️ 撰写完成后必须逐条核对：
> - [ ] 数据中的每个费用科目是否都在报告中有体现？
> - [ ] 费用总览表是否包含了所有费用大类（而非只列举部分）？
> - [ ] 异常分析是否覆盖了所有超支科目？
> - [ ] 控费建议是否覆盖了每个异常/超支科目？
> - [ ] **所有数值是否均来自原始数据？是否存在编造的数值？** 如果原始数据未提供预算值，报告中不得出现该数值
> - [ ] 预算执行率计算是否使用统一公式（实际/预算×100%）？
> - [ ] 建议措施是否都附带了预期节约效果？

## 写作要求
- 语言风格：正式、简洁，结论导向
- 数据要求：金额统一单位，百分比保留 1 位小数；预算执行率计算公式统一（实际/预算×100%）；同比环比数据必须准确
- 特殊约束：禁止编造费用数据；异常分析必须有数据支撑而非主观推测；建议措施需具体可执行并附预期效果
