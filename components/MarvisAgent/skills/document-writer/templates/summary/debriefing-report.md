# 述职报告模板

## 章节结构

### 第1章 个人概述
- **写作要点指导**：简要介绍个人基本信息（姓名、岗位、在岗时间），概述岗位核心职责与工作范围，一句话总结述职期内的工作基调与核心成就

### 第2章 岗位职责履行
- **写作要点指导**：逐项对照岗位职责描述，说明各项职责的履行情况与成果，使用表格呈现职责→具体工作→成果数据的对应关系，标注超额完成的职责与未完成的职责及原因

### 第3章 重点业绩展示
- **写作要点指导**：精选 3-5 个最具代表性的工作成果/项目进行深度展示，每个成果包含：背景与目标、个人角色与贡献、具体成果与数据、影响与价值。突出个人的独特贡献与不可替代性

### 第4章 关键数据指标
- **写作要点指导**：使用表格呈现核心 KPI/OKR 及达成情况（目标值 vs 实际值 vs 达成率），对标岗位要求或团队平均水平，分析超额完成或未达标指标的原因

### 第5章 能力成长与自我评价
- **写作要点指导**：总结述职期内在专业技能、管理能力、协作能力等方面的成长，诚实评价自身的优势与不足，说明为弥补不足所采取的行动（学习、培训、实践等）

### 第6章 未来规划
- **写作要点指导**：阐述下阶段的工作目标与发展方向，列出计划突破的重点领域，说明个人的职业发展期望（如适用），承诺具体的行动计划与时间节点

## 写作要求
- 语言风格：半正式、自信但不自夸，用数据说话
- 数据要求：核心成果必须有量化数据支撑；对比数据使用统一口径；数据来源需可验证
- 特殊约束：突出个人贡献而非团队功劳；问题与不足的反思要真诚有深度；避免流水账式叙述，每段需有明确的价值表达
