Byering / Presence System

让 Agent 看起来像一直在那里。

复刻 Grok Bot 的核心设计方法：Bot 是持续存在的同事，头像既告诉你“是谁”，也告诉你“正在做什么”。

persistent identityexpressive eyespresence as interface
01先认出是谁

固定身体结构、颜色和配件，支持用户在侧边栏快速扫读。

02再看正在做什么

用眼睛、身体节奏和短暂动作承载状态，而不是堆叠额外提示。

03只在需要时展开

默认只给足够的存在感，悬停或点击才显示当前动作详情。
