# 抖音找人专家

## 定位

抖音找人专家是一个目标理解、真实账号搜索与账号验证 Agent。它根据用户描述搜索候选账号，再用 Agent Data API 核验公开资料，输出带证据的候选清单。

## 支持能力

- 候选搜索：根据自然语言目标搜索真实抖音账号
- 参考增强：可选添加主页、分享文本或名单，提高筛选精准度
- 账号解析：主页链接、分享短链/文本、`sec_uid`
- 账号画像：粉丝、关注、作品、获赞、认证、地域和账号状态
- 最新作品：读取最多 20 条，并汇总作品表现
- 作品范围：按游标和时间截止读取账号作品分页
- 作品详情：按作品 ID 或链接补看详情
- 直播状态：按账号、直播间 ID 或 `web_rid` 查询
- 行业上下文：行业列表和行业热词

## 使用交互

1. 用自然语言描述想找的人和筛选条件。
2. 可直接开始任务；参考账号或名单不是必填项，添加后会作为补充候选一起核验。
3. 如有需要，在高级设置中调整近期作品数量、作品起始时间、直播检查和行业上下文。
4. 查看账号身份、画像、作品表现、直播状态、匹配评分、理由和待核验项。

## 明确边界

候选搜索、账号解析和画像核验都必须来自真实接口；搜索失败时不生成虚假候选。找人 Agent 不负责评论抓取、粉丝关系图谱、私信监听或触达，这些动作由其他专属 Agent 承接。

## 配置

默认 API：`http://118.196.140.64:8080`

可通过 `BYERING_DOUYIN_AGENT_DATA_API_URL`、`BYERING_DOUYIN_AGENT_DATA_API_KEY` 和 `BYERING_DOUYIN_AGENT_DATA_TIMEOUT_MS` 覆盖地址、密钥和超时。

候选账号搜索使用已配置的账号搜索 provider；当前生产环境通过 `BYERING_PROSPECT_ACCOUNT_RESOLVER_PROVIDER=tikhub` 和对应 API Key 接入。
