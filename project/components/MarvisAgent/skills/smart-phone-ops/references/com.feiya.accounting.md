# 飞鸭AI记账 App 操作规范

**类型**：`capture_screen` 截图 + `gui_grounder` 定位

## 核心特性

- **明细页采集策略**：无论用户需求是查看明细、消费汇总、分类统计还是生成报告，**统一在「明细」页面逐屏截图采集所有消费记录**，由 AI 自行汇总。**禁止使用「统计」页面**（坐标识别不稳定，交互易失败）。明细页信息已足够完整（分类图标、名称、金额、日期分组含当日收支汇总）。

- **详情页无需点开**：明细列表每条记录点开后无额外关键信息（无备注、商户名等），**禁止逐条点开详情页**，直接在列表页截图采集。**覆盖通用规范中"逐条点进详情页"的要求**。

## 操作流程

```
启动 App 后
  │
  ├─ 1. capture_screen 确认界面，处理可能出现的 VIP 广告弹窗（tap_back 关闭）
  │
  ├─ 2. 确认在「明细」tab（启动后默认），不在则点击底部最左侧切换
  │
  ├─ 3. 确认顶部月份为目标月份，不是则通过左右 < > 箭头切换（切换后数据自动刷新，需重新采集）
  │
  ├─ 4. 逐屏采集
  │     ├─ capture_screen 记录当前屏所有消费条目
  │     ├─ swipe 向下滑动，继续截图采集下一屏
  │     └─ 重复直到到底，注意按日期+分类+金额去重重叠记录
  │
  └─ 5. AI 汇总分类统计，输出报告
```

## 注意事项

- 底部导航栏 5 个 tab：**明细、自动记、+（记账）、统计、我的**。中间「+」按钮突出且热区大，点击「自动记」时注意避免误触，误触后 tap_back 返回即可
- VIP 购买弹窗频繁（全屏/底部横幅），优先 tap_back 关闭，每次截图时检查是否有新弹窗
