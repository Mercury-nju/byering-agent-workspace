# Keep 运动健身 App 操作规范

**类型**：普通 App（dump_ui 优先）

## 0. 核心特性

- 底部主 Tab：运动 / 饮食 / 发现 / 商城 / 我的
- 「今日」入口在底部 Tab 栏上方或「运动」Tab 内，显示今日运动目标与打卡状态
- 「我的」页面含个人运动数据（时长、千卡、天数）、体重、运动记录
- ⚠️ 部分功能需登录（个人数据、运动记录），未登录时弹出登录引导

## 1. 操作流程

### 1.1 查看今日运动数据

```
查看今日运动数据
  │
  ├─ 点击底部「今日」Tab（text="今日"，resource-id: textName）
  ├─ dump_ui 查看运动数据区域（运动时长如"0/20分钟"、目标完成状态）
  └─ 记录：今日运动时长、目标时长、消耗千卡、已完成项目
```

> ⚠️ 运动数据区域位置可能因版本不同有差异，有时需下滑查找。
> ⚠️ 当天无运动记录时如实报告。

### 1.2 查看个人数据与运动记录

```
查看个人运动数据
  │
  ├─ 点击底部「我的」Tab → dump_ui 感知页面
  │   记录：本周运动时长、总运动天数、体重
  │
  └─ 如需详细运动记录
      ├─ 查找「运动记录」/「运动数据」入口并点击
      ├─ 逐条查看详情（运动类型、时长、距离、千卡、配速/心率、日期）
      └─ tap_back 返回列表
```

> ⚠️ 「我的」页面需登录，未登录仅显示登录入口。

### 1.3 浏览与开始训练课程

```
浏览或开始训练
  │
  ├─ 在「运动」Tab 查找课程入口（text 含"训练"/"课程"/"计划"）
  ├─ 点击课程卡片，记录：名称、时长、难度、千卡
  ├─ ⚠️ 开始训练必须等用户确认后才能点击
  └─ tap_back 返回
```

## 2. App 特有弹窗

> 通用弹窗处理按通用规范 §1.2 执行。以下为 Keep 特有的弹窗类型：

| 弹窗类型 | 特征 | 处理 |
|---------|------|------|
| 运动提醒 | text 含"打卡提醒" | 点击关闭 |

## 3. 界面元素定位提示

| 目标元素 | dump_ui 搜索策略 | 备用方案 |
|---------|-----------------|---------|
| 底部 Tab（今日） | text="今日"（resource-id: textName） | 底部第二个 |
| 底部 Tab（运动） | text="运动"（resource-id: textName） | 底部中间 |
| 底部 Tab（我的） | text="我的"（resource-id: textName） | 底部最右 |
| 搜索栏 | resource-id="com.gotokeep.keep:id/layoutSearch" | 顶部搜索框 |
| 运动时长 | text 匹配"X/X分钟"格式 | 今日区域 |
| 我的数据 | text 含"我的数据" 且 clickable=true | 我的页面 |
| 开始训练按钮 | text="开始训练" 且 clickable=true | 课程详情页底部 |

## 4. 结果输出格式

### 今日运动数据

```markdown
### 📊 今日运动数据
- **日期**：YYYY-MM-DD
- **运动时长**：X/X 分钟
- **消耗**：X kcal
- **打卡状态**：✅ 已完成 / ❌ 未完成
```

### 个人运动数据

```markdown
### 📈 个人运动数据
- **本周运动**：X 分钟
- **总运动天数**：X 天
- **体重**：X.X 公斤
- **最近运动记录**：
  | 日期 | 类型 | 时长 | 距离 | 消耗 |
  |------|------|------|------|------|
  | MM-DD | 户外跑步 | 29分 | 5.04km | 327kcal |
```

### 健康报告

```markdown
### 🏃 今日健康报告
📅 日期：YYYY-MM-DD
【运动数据】运动时长 X/X 分钟，消耗 X kcal
【身体数据】体重 X.X 公斤
【健康建议】根据今日运动情况给出个性化建议
```
