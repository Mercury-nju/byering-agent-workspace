# 剪映 App 操作规范

**类型**：普通 App（dump_ui 优先）

## 0. 核心特性

> 因已知 resource-id 丰富（§0.5 元素字典），优先通过 `dump_ui` + resource-id 定位；横屏编辑界面中时间线等自绘元素需回退截图+ `gui_grounder`。

- **横屏编辑模式**：进入编辑界面后 App 自动切换为横屏（rotation=3），屏幕宽高互换
- **dump_ui 实际可用**：⭐ 实测发现，横屏模式下 dump_ui 能返回有效 bounds（包括导出、变速、分割等按钮），大部分操作无需截图回退
- **自绘 UI 混合**：编辑界面中的时间线内部元素、变速滑块等为自绘元素，dump_ui 无法获取，需使用截图+ `gui_grounder` 识别
- **文件路径注意**：向模拟器推送文件时，路径必须使用正斜杠（`C:/Users/...`），不可使用反斜杠
- **已知元素字典**：§0.5 章节收录了经验证的 resource-id / text 定位信息（跨设备通用），首次操作时 dump_ui 获取实际坐标即可

> ⚠️ **操作优先级**：`dump_ui` + resource-id/text → bounds 中心坐标 → 操作。自绘元素兜底截图+ `gui_grounder`。

## 0.5 已知元素字典（⭐跨设备通用，resource-id / text 定位）

> ⚠️ **设计原则**：本章节只记录**与设备无关的通用信息**（resource-id、text、元素层级关系、操作顺序），
> 不硬编码 bounds 坐标，因为这些值会随模拟器分辨率/DPI 变化。
>
> **使用方式**：通过 `dump_ui` 按 resource-id 或 text 搜索元素 → 从返回的 bounds 计算中心坐标 → android_tap/focus_at。
> 比盲目探索快得多，因为你已经知道要找什么。

### 0.5.4 快速操作路径指南

> 以下操作流程跨设备通用。坐标通过 dump_ui + resource-id/text 实时获取。

| 操作 | 快速路径 |
|------|---------|
| 打开草稿 | dump_ui → 找 `#mDraftGridView` 的子元素 → 点击目标草稿 |
| 新建项目 | dump_ui → 找 `#mNewProject` → 计算中心坐标 → android_tap/focus_at |
| 导出视频 | dump_ui → 找 `#tvExport` → 计算中心坐标 → android_tap/focus_at |
| 分割视频 | 选中素材 → dump_ui → 找 text="分割" → android_tap/focus_at |
| 变速 | 选中素材 → dump_ui → 找 text="变速" → android_tap/focus_at |
| 播放/暂停 | dump_ui → 找 `#ivPlay` → android_tap/focus_at |
| 返回 | dump_ui → 找 `#tvBack` → android_tap/focus_at |
| 添加媒体 | dump_ui → 找 `#ivAdd2` → android_tap/focus_at |

> 💡 **同一界面内的多个操作只需 dump_ui 一次**——一次 dump 获取整个控件树，然后按 resource-id/text 查找多个元素的 bounds，批量计算中心坐标后依次点击。

## 1. 启动后与项目进入流程

### 1.1 操作流程

```
用户提出剪映操作需求
  │
  ├─ Step 1. 处理启动弹窗（按通用规范中断处理）
  │     └─ App 特有：VIP 推广弹窗 → 查找关闭按钮(×)点击（dump_ui 优先，零坐标时截图定位）
  │
  ├─ Step 2. 确认到达首页（项目管理页面）
  │     ├─ dump_ui 确认看到"开始创作"按钮或"本地草稿"区域
  │     └─ 如果需要编辑已有项目，点击草稿列表中的目标项目
  │
  └─ Step 3. 进入编辑界面
        ├─ 新建项目：点击"开始创作" → 选择素材 → 进入编辑
        ├─ 打开草稿：点击草稿项目 → 进入编辑界面
        └─ 进入编辑界面后 App 会自动切换为横屏模式
```

### 1.2 注意事项

- **隐私协议**：首次启动必须同意隐私协议才能使用，dump_ui 查找 text 含"同意"的按钮
- **横屏切换**：进入编辑界面后屏幕自动横屏，后续所有操作基于横屏坐标

## 2. 素材导入流程

### 2.1 从 Windows 推送素材到模拟器

```
用户需要导入外部素材（视频/图片/音频）
  │
  ├─ Step 1. 使用 push_file 推送文件到模拟器
  │     ├─ 目标路径默认为 Pictures 目录
  │     ├─ 🔴 文件路径必须使用正斜杠：C:/Users/xxx/file.mp4
  │     └─ 禁止使用反斜杠路径（会导致推送失败）
  │
  ├─ Step 2. 在剪映中导入素材
  │     ├─ 点击"开始创作"或编辑界面中的"+"导入按钮
  │     ├─ 在素材选择器中找到推送的文件
  │     └─ 选中文件后点击"添加"/"导入"
  │
  └─ Step 3. 确认素材已添加到时间线
        └─ dump_ui 或截图确认时间线上出现新素材
```

### 2.2 注意事项

- **路径格式红线**：`push_file` 的 Windows 路径必须用正斜杠 `/`，反斜杠 `\` 会导致失败
- **文件名编码**：含中文括号等特殊字符的文件名可能导致问题，建议先确认文件名

## 3. 视频编辑操作

### 3.1 视频变速

```
在编辑界面中
  │
  ├─ Step 1. 在时间线上点击选中目标视频片段
  │     └─ dump_ui 找 `#trackContainer` 区域内的素材元素并点击
  │
  ├─ Step 2. 点击变速按钮
  │     └─ dump_ui 找 text="变速" 的元素 → 计算中心坐标 → android_tap/focus_at（见 §0.5.3）
  │
  ├─ Step 3. 进入变速设置界面
  │     ├─ 确认"常规变速"Tab 已选中（默认选中）
  │     └─ 定位速度滑块或速度值区域（需 dump_ui 或截图+ `gui_grounder` 识别，此处为动态面板）
  │
  ├─ Step 4. 调整速度
  │     ├─ 方案A（滑块拖动）：计算滑块目标位置，使用 swipe 拖动
  │     │   └─ 滑块通常为水平方向，从当前位置滑动到目标倍速位置
  │     └─ 方案B（数值输入）：如有输入框，点击后输入目标倍速值
  │
  └─ Step 5. 确认变速结果
        └─ 截图确认速度值已变更，时间线素材长度有变化
```

### 3.2 视频分割

```
在编辑界面中
  │
  ├─ Step 1. 在时间线上定位到目标分割位置
  │     └─ 滑动时间线或点击时间刻度定位播放头（dump_ui 找 `#ivPlayHead`）
  │
  ├─ Step 2. 选中素材后点击"分割"按钮
  │     └─ dump_ui 找 text="分割" 的元素 → 计算中心坐标 → android_tap/focus_at（见 §0.5.3）
  │
  └─ Step 3. 确认分割完成
        └─ 截图确认时间线上素材被分割为两段
```

### 3.3 注意事项

- **选中状态确认**：操作变速、分割等功能前，必须先在时间线上选中目标素材片段
- **底部工具栏**：选中素材后底部会出现功能工具栏（剪辑/变速/音量/动画/滤镜等）
- **滑块方向**：变速滑块为水平方向滑动，向右拖动增加速度，向左减少速度

## 4. 视频导出流程

### 4.1 操作流程

```
编辑完成后准备导出
  │
  ├─ Step 1. 点击导出按钮
  │     ├─ dump_ui 找 `#tvExport`（text="导出"）→ 计算中心坐标 → android_tap/focus_at
  │     └─ 参见 §0.5.2 顶部工具栏的 resource-id
  │
  ├─ Step 2. 导出配置页面（可选）
  │     ├─ 如果出现导出参数设置页（分辨率/帧率/码率）
  │     ├─ 通常保持默认设置即可
  │     └─ 点击"导出"/"开始导出"按钮
  │
  ├─ Step 3. 等待导出完成
  │     ├─ 导出过程中会显示进度条（"努力导出中...请保持屏幕点亮"）
  │     ├─ 🔴 截图轮询导出进度，每 8-10 秒截图一次检查
  │     └─ 直到看到"恭喜你完成视频创作"或"导出成功"提示
  │
  ├─ Step 4. 处理导出完成后的 VIP 弹窗
  │     ├─ 导出成功后高概率弹出 VIP 推广弹窗
  │     ├─ dump_ui 查找 resource-id 含 "ivClose" 或 "close" 的关闭按钮
  │     ├─ 如果 dump_ui 中关闭按钮 bounds 为 [0,0,0,0]
  │     │   └─ 截图+ `gui_grounder` 定位弹窗右上角的 X 关闭按钮并点击
  │     └─ 可能需要多次尝试才能准确点击关闭按钮
  │
  └─ Step 5. 点击"完成"返回
        ├─ 关闭 VIP 弹窗后，页面显示"保存到相册和草稿"
        ├─ 底部有"完成"按钮
        └─ 点击"完成"返回剪映主页
```

### 4.2 注意事项

- **导出耗时**：视频导出需要时间，15秒短视频约需15-30秒，长视频更久
- **VIP 弹窗必处理**：导出成功后几乎必定弹出 VIP 推广弹窗，必须关闭后才能继续
- **导出文件位置**：导出的视频保存在模拟器的 DCIM/Camera 或 Movies 目录
- **导出到桌面**：Androws MCP 只有 push_file（推送到模拟器），没有从模拟器拉取文件的工具；如需将导出视频传到 Windows 桌面，需通过模拟器共享目录或其他方式

## 5. 横屏模式坐标处理规范

> ⚠️ 这是剪映 App 最关键的差异化要点，横屏模式下的坐标处理与普通竖屏 App 完全不同。

### 5.1 横屏模式识别

- 进入编辑界面后，App 自动切换横屏

### 5.2 横屏下 dump_ui 的情况

> 🟢 **实测发现**：横屏编辑模式下 dump_ui 能返回有效 bounds 坐标（包括导出、变速、分割、工具栏等），**大部分元素并非零坐标**, 可直接使用。
>
> **操作优先级**：同 §0 — `dump_ui` + resource-id/text 优先，自绘元素或零坐标回退截图+ `gui_grounder`。

- **可能零坐标的元素**：时间线内部的自绘元素（如变速滑块刻度、时间线缩放手势区域等）
- **已确认有效坐标的元素**：导出按钮、分割、变速、返回、播放/暂停、底部工具栏等（详见 §0.5.2/§0.5.3 的 resource-id）

### 5.3 感知策略决策树（⭐）

```
需要定位编辑界面中的元素
  │
  ├─ Step 1.【推荐】dump_ui + §0.5 元素字典
  │     ├─ dump_ui 获取控件树
  │     ├─ 按 §0.5 中的 resource-id / text 搜索目标元素
  │     ├─ 目标元素 bounds 有效（非零）→ 计算中心坐标并 android_tap/focus_at
  │     └─ 目标元素 bounds 为 [0,0,0,0] → 进入 Step 2
  │
  └─ Step 2. 切换截图方案
        ├─ capture_screen 截图，同时记录`image_size`
        ├─ 使用 `gui_grounder` 定位元素精确坐标
        └─ 执行操作：务必传入参数 `source=screenshot`和`image_size`
```

## 7. App 特有弹窗

> 通用弹窗处理按通用规范 §1.2 执行。以下为剪映特有的弹窗类型：

| 弹窗类型 | 出现时机 | 处理方式 |
|---------|---------|---------|
| 隐私协议 | 首次启动 | 点击"同意"（必须同意才能继续） |
| 版本更新 | 启动时 | 点击"稍后再说"/"取消" |
| VIP 推广 | 导出成功后、启动后 | 查找关闭按钮(×)，dump_ui 优先，零坐标时使用截图+ `gui_grounder` 定位 |
| 权限申请（存储/相机） | 导入素材/录制时 | 点击"允许" |
| 登录引导 | 部分功能操作时 | 非强制则关闭/跳过，强制则通知用户接管 |
| 活动推广/运营弹窗 | 随机出现 | 查找关闭按钮或 escape 键关闭 |
