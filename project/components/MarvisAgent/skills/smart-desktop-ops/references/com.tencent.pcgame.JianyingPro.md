# 剪映电脑版 桌面应用操作规范

## 0. 应用概述

**应用类型**：native（原生 Windows 应用）

**窗口特征**：
- 主窗口为**四区域多面板布局**：顶部工具栏、左侧素材/音频面板、中央播放器+右侧属性面板、底部时间线
- 界面为深色主题，自绘引擎渲染，所有 UI 元素需通过截图视觉识别
- 右侧属性面板有**两种状态**：未选中素材时显示"草稿参数"；选中素材后切换为功能 Tab 栏

## 0.1 参数规则

**本 App 推荐窗口名**：`app_name="JianyingPro"`（备选 `"剪映"`）

**App 特有规则**：
1. **观察界面优先使用 `exe_capture_window`**：禁止使用 `exe_capture_screen` 作为默认观察方式。
2. **对清晰的文字标签可尝试 `exe_dump_ui`**：如"音频"、"变速"、"常规变速"等；若 OCR 识别不稳定，则回退到窗口截图 + `gui_grounder`。

## 2. 核心操作流程

### 2.1 视频变速（示例：3 倍速）

```
在时间线中选中目标视频片段（点击视频轨道上的素材块）
  │
  ├─ 1. exe_capture_window(app_name="JianyingPro") 确认右侧面板已切换为功能 Tab 栏
  │     （应显示「画面 | 变速 | 动画 | 调整 | AI效果」Tab）
  │
  ├─ 2. 点击「变速」Tab
  │     ├─ 文字识别稳定时：exe_dump_ui → 用 source="ocr" + app_name 点击
  │     └─ OCR 不稳定时： 调用 `exe_capture_window` + `gui_grounder` 获取位置 → 用 source="window" + app_name 点击
  │
  ├─ 3. exe_capture_window(app_name="JianyingPro") 确认进入变速设置界面
  │     （应显示「常规变速 | 曲线变速」二级 Tab 和速度滑块）
  │
  ├─ 4. 确认选中「常规变速」Tab（默认选中）
  │
  ├─ 5. 定位速度值输入框（显示当前倍速的数字区域）
  │     ├─ 点击速度值输入框使其获得焦点
  │     ├─ exe_press_key("ctrl+a") 全选当前值
  │     └─ exe_input_text("3.0") 输入目标倍速
  │
  ├─ 6. exe_press_key(key_name="enter") 确认输入
  │
  └─ 7. exe_capture_window(app_name="JianyingPro") 验证变速结果
        （时间线上素材块长度应变短，速度值显示 3.0x）
```

### 2.2 添加音频配乐

⚠️ **【搜索交互红线】禁止使用回车键触发搜索！** 剪映音频搜索使用联想下拉方式，输入关键词后等待联想列表出现，点击第一个联想词触发搜索。

```
在编辑界面中
  │
  ├─ 1. 点击左侧素材工具栏中的「音频」Tab
  │     （图标为音符 ♪ 形状，位于左侧工具栏第 2 个位置）
  │
  ├─ 2. exe_capture_window(app_name="JianyingPro") 确认左侧面板已切换为音频面板
  │     （应显示搜索框和音乐/音效/提取音频等分类）
  │
  ├─ 3. 点击音频面板顶部的搜索框使其获得焦点
  │
  ├─ 4. exe_input_text("<用户指定的音乐名>") 输入搜索关键词
  │
  ├─ 5. 🔴【关键】等待 2-3 秒，让搜索联想下拉列表出现
  │     exe_capture_window(app_name="JianyingPro") 确认联想列表已显示
  │
  ├─ 6. 🔴 点击联想下拉列表中的**第一个联想词**触发搜索
  │     （联想词通常在搜索框正下方，注意不要误点其他区域）
  │
  ├─ 7. exe_capture_window(app_name="JianyingPro") 确认搜索结果列表已加载
  │     （应显示匹配的音乐列表，每条包含歌名、时长、使用按钮）
  │
  ├─ 8. 定位搜索结果中的第一个最匹配音乐
  │
  ├─ 9. hover 音乐条目，等待操作按钮出现
  │     （通常出现「使用」或「+」按钮）
  │
  ├─ 10. 点击「使用」按钮将音乐添加到时间线
  │
  └─ 11. exe_capture_window(app_name="JianyingPro") 验证音频已添加到时间线
        （时间线音频轨道应出现新的音频素材块）
```

### 2.3 注意事项

- **搜索联想替代回车**：剪映音频搜索框禁止用回车触发，必须等待联想下拉列表出现后点击联想词
- **素材选中状态**：操作变速、动画等属性前，必须先在时间线上点击选中目标素材片段
- **右侧面板状态判断**：操作前截图确认右侧面板当前状态（草稿参数 vs 功能 Tab 栏）
- **hover 触发按钮**：音乐列表中的「使用」按钮通常需要 hover 才显示，先 `exe_mouse(mouse_action="move")` 到条目上方等待按钮出现
- **输入法切换**：输入文字前确保输入法处于正确状态，使用 `exe_input_text` 可绕过 IME 直接输入中文

## 3. 应用专属快捷键

以下为剪映电脑版特有的快捷键：

| 快捷键 | 功能 |
|--------|------|
| `space` | 播放/暂停预览 |
| `ctrl+b` | 分割（在播放头位置剪切当前素材） |
| `+` / `-` | 时间线缩放（放大/缩小） |
| `left` / `right` | 逐帧移动播放头 |

## 5. 特殊场景处理

### 5.1 右侧属性面板状态判断

右侧属性面板有**两种互斥状态**，操作前必须截图确认：

| 当前状态 | 视觉特征 | 触发条件 |
|---------|---------|---------|
| **草稿参数** | 显示"分辨率""帧率""背景色"等设置项 | 未选中时间线上的任何素材 |
| **功能 Tab 栏** | 顶部显示「画面 \| 变速 \| 动画 \| 调整 \| AI效果」 | 已在时间线上选中了某个素材片段 |

⚠️ 如果需要操作变速、动画等功能但右侧面板显示"草稿参数"，说明未选中素材。必须先在时间线上点击选中目标素材片段。

### 5.2 音频搜索联想交互

```
输入关键词后的处理流程：
  │
  ├─ 输入文字 → 等待 2-3 秒（wait）
  │
  ├─ exe_capture_window(app_name="JianyingPro") 检查联想下拉列表
  │   ├─ 已出现联想列表 → 点击第一个联想词
  │   └─ 未出现联想列表 → 再等待 1-2 秒后重新截图
  │
  └─ 🔴 禁止使用 exe_press_key(key_name="enter") 触发搜索
```

### 5.3 启动与项目进入

```
启动剪映后：
  │
  ├─ 等待 5-8 秒（大型应用加载较慢）
  │
  ├─ exe_capture_window(app_name="JianyingPro") 检查当前界面
  │   ├─ 如果在项目管理页面 → 点击打开已有项目或新建项目
  │   ├─ 如果有登录/更新弹窗 → 关闭弹窗或选择"稍后"
  │   └─ 如果已在编辑界面 → 继续操作
  │
  └─ 进入编辑界面后，截图确认四区域布局可见
```

### 5.4 弹窗处理

通用弹窗处理按通用规范「中断处理」执行。以下为剪映特有的弹窗类型：

| 弹窗类型 | 处理方式 |
|---------|---------|
| 会员推广（导出后） | 查找关闭按钮（×）或"关闭"按钮 |
| 模板推荐 | 查找关闭按钮或 `exe_press_key(key_name="escape")` |

### 5.5 时间线操作技巧

- **选中素材**：在时间线轨道区域点击目标素材块（带缩略图的彩色条）
- **移动播放头**：点击时间刻度尺上的目标位置
- **缩放时间线**：使用 `+` / `-` 键或鼠标滚轮（在时间线区域内）
- **滚动时间线**：在时间线区域内水平滚动查看更多内容
- **分割素材**：将播放头移到目标位置，按 `ctrl+b` 分割
