# 财务分析报告模板

## 章节结构

### 第1章 执行摘要
- **写作要点指导**：概述财务分析的核心发现（3-5 条关键结论），列出关键财务指标速览（营收、利润、增长率等），给出明确的财务评价与建议。摘要应可独立阅读

### 第2章 分析背景与范围
- **写作要点指导**：说明分析的时间范围（如 FY2024、Q1-Q3），明确分析对象（公司整体/事业部/项目），列出数据来源（财报、内部系统、审计报告等），说明分析方法与关键假设

### 第3章 营收与利润分析
- **写作要点指导**：呈现营收总量及增长趋势（同比/环比），按业务线/产品线/区域拆解收入结构，分析毛利率、营业利润率、净利率的变化趋势，识别收入增长/下降的关键驱动因素。使用表格呈现收入结构明细

### 第4章 成本与费用结构
- **写作要点指导**：拆解成本构成（原材料、人力、折旧等），分析各项成本占比及变化趋势，对比期间费用率（销售费用率、管理费用率、研发费用率），识别成本异常波动及原因

### 第5章 资产负债分析
- **写作要点指导**：评估资产结构与质量（流动资产/非流动资产占比），分析负债结构与偿债能力（资产负债率、流动比率、速动比率），评估应收账款周转与库存管理效率，分析净资产变化与股东权益

### 第6章 现金流分析
- **写作要点指导**：分析经营性现金流的充裕度与质量，评估投资活动现金流（资本开支、投资收益），分析筹资活动现金流（融资、分红），评估自由现金流与现金储备

### 第7章 关键财务指标对比
- **写作要点指导**：使用表格汇总核心财务指标（盈利能力、运营效率、偿债能力、成长能力），进行同比/环比对比，对标行业平均水平或竞争对手（如有），标注异常指标并分析原因

### 第8章 风险提示与建议
- **写作要点指导**：识别财务层面的主要风险（流动性、偿债、盈利持续性等），给出针对性的改善建议（成本优化、结构调整、现金流管理等），区分短期行动与中长期策略

### 附录
- **写作要点指导**：完整财务数据明细表、指标计算公式说明、数据来源列表

## 撰写原则

1. **数据驱动**：所有结论必须有数据支撑，禁止主观臆断
2. **全面覆盖**：**必须分析数据中出现的所有财务维度/科目/指标**，不得遗漏。如数据包含 N 个维度，报告必须覆盖全部 N 个维度
3. **不编造数据**：报告中出现的所有数值必须来源于原始数据，**绝对禁止凭常识或假设编造**。如果原始数据中没有提供某个基准值（如行业均值、目标值等），**必须省略该列或标注"未提供"**，不得自行填写
4. **优劣并述**：客观呈现财务优势与风险，不报喜不报忧
5. **层次分明**：从概览到细节，逻辑递进
6. **语言专业**：使用标准财务术语，表述简洁严谨，避免口语化

- ❌ "需要加强成本管控" → 太笼统

## 质量检查清单

> ⚠️ 撰写完成后必须逐条核对：
> - [ ] 数据中的每个财务维度/科目/指标是否都在报告中有体现？
> - [ ] 财务数据明细表是否包含了所有业务线/科目（而非只列举部分）？
> - [ ] 优势和风险的分析是否基于全部维度进行排序和筛选？
> - [ ] 建议是否覆盖了表现异常的每个维度（而非只关注部分维度）？
> - [ ] **所有数值是否均来自原始数据？是否存在编造的数值？** 如果原始数据未提供某个基准值，报告中不得出现该数值
> - [ ] 金额单位是否统一（万元/亿元）？百分比是否保留1位小数？
> - [ ] 同比/环比数据是否计算准确？
> - [ ] 事实与推测是否明确区分？

## 写作要求
- 语言风格：正式、严谨专业，使用标准财务术语
- 数据要求：所有财务数据必须标注来源与时间口径；金额统一单位（万元/亿元）；百分比保留 1 位小数；同比/环比数据必须计算准确
- 特殊约束：绝对禁止编造财务数据；事实与推测必须明确区分；涉及敏感数据时需标注保密级别
