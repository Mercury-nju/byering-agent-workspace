# 满意度分析报告模板

## 章节结构

### 第1章 核心摘要
- **写作要点指导**：概述调查的基本信息（调查对象、样本量、回收率），列出整体满意度评分与 NPS 值，标注最满意与最不满意的维度，给出 3-5 条关键发现

### 第2章 调查概况
- **写作要点指导**：说明调查背景与目的，描述调查方法（问卷设计、发放渠道、评分量表），展示样本分布（按部门/角色/地域/客户类型等），分析样本的代表性与局限性

### 第3章 整体满意度分析
- **写作要点指导**：呈现整体满意度评分（均分、中位数、分布），计算 NPS/CSAT 值及各档占比（推荐者/被动者/贬损者），对比上期数据的变化趋势，与行业基准或内部目标对比（如有）

### 第4章 维度分析
- **写作要点指导**：使用表格逐维度呈现满意度评分（如产品质量、服务态度、响应速度、价格等），按评分高低排序，识别优势维度与短板维度，分析各维度的权重/重要性（如有回归分析数据），对比各维度的历史变化趋势

### 第5章 分群对比分析
- **写作要点指导**：按人群/客户分组对比满意度差异（如新客户 vs 老客户、不同区域、不同产品线），识别满意度显著偏低的细分群体，分析群体间差异的可能原因

### 第6章 开放性反馈分析
- **写作要点指导**：对开放题回答进行主题聚类与频次统计，提取正面反馈的高频关键词与代表性原文，提取负面反馈的高频关键词与代表性原文，识别反复被提及的具体问题

### 第7章 改进建议
- **写作要点指导**：基于短板维度和负面反馈给出具体改进措施，按优先级排序（高影响+低满意度优先），区分短期快赢与中长期改善，给出下次调查的建议（问卷优化、频率调整等）

### 附录
- **写作要点指导**：问卷原文、完整数据表、统计方法说明

## 撰写原则

1. **数据驱动**：所有结论必须有调查数据支撑，禁止主观臆断
2. **全面覆盖**：**必须分析数据中出现的所有满意度维度**，不得遗漏。如调查包含 N 个维度，报告必须覆盖全部 N 个维度
3. **不编造数据**：报告中出现的所有数值必须来源于原始调查数据，**绝对禁止凭常识或假设编造**。如果原始数据中没有提供行业基准值，**必须省略该列或标注"未提供"**
4. **优劣并述**：客观呈现满意度高分项与低分项，不选择性呈现
5. **统计严谨**：注意样本量是否充分，避免过度解读小样本差异

### 建议撰写标准

- ❌ "需要提高服务质量" → 太笼统
- ✅ "售后响应速度评分 3.2 分（满分5分），为最低维度，且较上期下降 0.4 分。分群分析显示大客户（年消费>10万）的不满最为突出（2.8分）。建议：① 大客户设专属客服经理；② 建立2小时内响应SLA；③ 引入智能客服分流简单问题" → 有数据、有分群洞察、有分级方案

## 质量检查清单

> ⚠️ 撰写完成后必须逐条核对：
> - [ ] 调查中的每个满意度维度是否都在报告中有体现？
> - [ ] 维度明细表是否包含了所有维度（而非只列举部分）？
> - [ ] 优势和短板的分析是否基于全部维度进行排序和筛选？
> - [ ] 改进建议是否覆盖了每个低分维度？
> - [ ] **所有数值是否均来自原始调查数据？是否存在编造的数值？** 如果原始数据未提供行业基准，报告中不得出现该数值
> - [ ] 样本量是否足以支撑分群对比结论？
> - [ ] 引用的原始反馈是否已脱敏处理？

## 写作要求
- 语言风格：正式、客观，数据导向
- 数据要求：评分保留 1 位小数；百分比保留 1 位小数；标注样本量与置信度（如有）；对比数据使用统一口径
- 特殊约束：引用原始反馈时需脱敏处理；统计结论需注意样本量是否充分；避免过度解读小样本差异
