# 人才盘点报告模板

## 章节结构

### 第1章 执行摘要
- **写作要点指导**：概述盘点范围与核心发现（团队规模、关键人才数、风险岗位数），列出人才梯队健康度的整体评价，给出最关键的 3-5 条行动建议

### 第2章 盘点背景与方法
- **写作要点指导**：说明盘点的触发背景（年度例行、组织变革、业务扩张等），明确盘点范围（组织层级、部门、岗位族群），介绍评估框架与维度定义（如绩效、潜力、价值观、核心能力），说明数据来源（绩效系统、360 评估、管理者访谈等）

### 第3章 人才数据总览
- **写作要点指导**：使用表格呈现盘点人群的基本画像（人数、层级分布、司龄分布、学历分布），统计人才结构比例（高潜占比、关键岗位覆盖率、继任准备度），展示人才流动数据（入职率、离职率、内部调动率）

### 第4章 绩效-潜力矩阵分析
- **写作要点指导**：呈现九宫格/四象限分布结果（每个象限的人数与占比），分析各象限的典型特征与管理策略，重点分析高绩效高潜力（明星人才）与低绩效低潜力（待观察）群体，对比上期盘点的矩阵变化（如有）

### 第5章 关键岗位与继任分析
- **写作要点指导**：识别关键岗位清单及其重要性评级，评估各关键岗位的继任准备度（就绪/1-2年可就绪/无继任），分析继任缺口与风险等级，给出继任培养建议

### 第6章 人才风险分析
- **写作要点指导**：识别高离职风险人员（结合绩效、满意度、市场竞争力等），分析关键岗位的单点风险（仅一人可胜任），评估团队能力短板与结构性风险，给出风险缓解措施

### 第7章 发展建议与行动计划
- **写作要点指导**：针对不同九宫格象限给出差异化的发展策略，制定高潜人才加速培养计划，提出团队能力短板的补强方案，使用表格呈现行动计划（措施→负责人→时间节点→预期效果）

### 附录
- **写作要点指导**：评估维度定义与评分标准、盘点数据明细、九宫格完整名单（如适用）

## 撰写原则

1. **数据驱动**：所有评估结论必须有多维数据支撑，禁止单一指标定性或主观臆断
2. **全面覆盖**：**必须覆盖盘点范围内的所有评估维度和关键岗位**，不得遗漏
3. **不编造数据**：报告中出现的所有数值必须来源于原始盘点数据，**绝对禁止凭常识或假设编造**。如果原始数据中没有提供某个基准值（如行业离职率），**必须省略或标注"未提供"**
4. **优劣并述**：客观呈现人才优势与风险，既肯定亮点也揭示隐患
5. **隐私保护**：涉及个人评价时使用编号或代称保护隐私（除非明确为内部机密报告）
6. **建议分层**：行动建议必须分层（个人级、团队级、组织级）

## 质量检查清单

> ⚠️ 撰写完成后必须逐条核对：
> - [ ] 盘点范围内的每个评估维度是否都在报告中有体现？
> - [ ] 九宫格/四象限是否覆盖了所有盘点人员？
> - [ ] 关键岗位清单是否完整？继任分析是否覆盖每个关键岗位？
> - [ ] **所有数值是否均来自原始盘点数据？是否存在编造的数值？**
> - [ ] 涉及个人评价时是否使用了编号/代称保护隐私？
> - [ ] 行动建议是否分层（个人级、团队级、组织级）？
> - [ ] 评估结论是否有多维数据交叉验证（而非单一指标定性）？

## 写作要求
- 语言风格：正式、客观审慎，兼顾战略视角与个体尊重
- 数据要求：盘点数据必须有明确来源；评估结果需注明评估方式（360、管理者评估等）；比例数据保留 1 位小数
- 特殊约束：涉及个人评价时使用编号或代称保护隐私（除非明确为内部报告）；评估结论必须有多维数据支撑，避免单一指标定性；建议必须分层（个人级、团队级、组织级）
