# 会议纪要模板

## 章节结构

### 第1章 会议信息
- **写作要点指导**：使用表格记录会议基本信息：会议主题、日期时间、地点/线上链接、主持人、记录人、参会人员列表。如有缺席人员也需标注

### 第2章 会议背景与目标
- **写作要点指导**：简述本次会议的召开背景（为什么开这个会），明确会议要达成的目标/要解决的问题，列出会议议程大纲

### 第3章 议题讨论记录
- **写作要点指导**：按议程顺序记录每个议题的讨论要点。每个议题包含：议题名称、汇报人/讨论发起人、核心讨论内容（各方观点）、讨论结论。使用清晰的层级结构区分不同议题

### 第4章 决策记录
- **写作要点指导**：使用表格汇总本次会议做出的所有决策。每条决策包含：决策事项、决策内容、决策人、生效日期。决策记录应简洁明确，便于后续追溯

### 第5章 待办事项（Action Items）
- **写作要点指导**：使用表格列出所有待办事项。每项包含：待办事项描述、负责人、截止日期、优先级（P0/P1/P2）。待办事项必须具体可执行、可验收

### 第6章 下次会议安排
- **写作要点指导**：确认下次会议时间、地点、主要议题预告，明确需要各方会前准备的事项

## 写作要求
- 语言风格：正式、简洁、客观，忠实记录而非加工
- 数据要求：讨论中涉及的数据需准确记录；引用发言人的观点需标注发言人
- 特殊约束：区分"讨论内容"和"决策结论"，不混淆；待办事项必须有明确的负责人和截止日期；敏感信息需标注"仅限内部传阅"
