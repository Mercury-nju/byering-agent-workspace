# 方案策划类写作规范（proposal）

> 适用于 `templates/proposal/` 下所有模板（营销策划、技术方案、需求文档、项目方案、旅游攻略等）。
> 与 `SKILL.md` 中的"通用写作规范"**叠加生效**，本文件条目**优先级更高**。

## 核心范式
**面向目标、设计路径**。产出以**可执行的计划和方案**为导向，能被立即拿去落地，三条底线：

1. **目标先行**：先明确**量化目标**（KPI/ROI/SLA/里程碑），目标不清则方案无从评价。
2. **逻辑闭环**：`背景/问题 → 目标 → 策略 → 执行 → 资源 → 风险 → 评估` 链条完整，不跳段。
3. **可执行性**：每项策略落到具体动作（任务 + 负责人 + 时间 + 验收标准）。

## 目标量化（必守 SMART）
Specific / Measurable / Assignable / Relevant / Time-bound，五要素缺一不可。

- ❌ 空目标："提升品牌影响力"、"增强用户体验"、"优化系统架构"
- ✅ 量化：  "6 个月内品牌搜索指数从 3200 提升至 5000"、"核心接口 P99 从 800ms 降至 300ms"

## 策略与执行的逻辑链
`市场/现状分析 → 洞察/切入点 → 核心策略(1-3 条主线) → 渠道/手段组合 → 执行计划(时间表+分工) → 预算 → 评估体系 → 风险预案`

上一环节是下一环节的**输入依据**。若"策略"推不出"执行"或"执行"推不出"预算"，说明逻辑链断裂。

## 执行计划（甘特图或时间表格）
至少含：`阶段 / 任务 / 关键交付物 / 负责人 / 开始 / 截止 / 依赖`

- 所有任务**必须有负责人**（未定也标出）。
- 关键任务标识**依赖关系**（前置任务 / 资源 / 外部条件）。
- 阶段间设**里程碑**与**验收标准**。

## 预算 & ROI
- **预算明细**：分项列出（渠道/内容/工具/人力），每项给出金额 + 占比 + **计算依据**。
- **必须预估**：CAC = 投入 ÷ 获客数；ROI = (收益 - 成本) ÷ 成本；回本周期。
- 每个数字都要能回答"这个数怎么算出来的"。

## 风险 & 应急
风险清单至少覆盖四类：**预算风险 / 执行风险 / 效果风险 / 外部风险**。
每项给出：**触发条件 → 影响评级（高/中/低）→ 预防措施 → 应急预案 → 止损阈值**。

## 评估体系
- 核心 KPI 3-5 个（不堆砌）。
- 明确**数据来源 + 监测频率**（日/周/月）。
- 评估节奏：周度快速复盘 + 月度策略校准 + 阶段总评。
- 配套调优机制：A/B 测试、阶段止损、预算重分配规则。

## 方案类自审清单
- [ ] 是否明确**量化目标**且全部满足 SMART？是否存在空目标？
- [ ] 章节间是否构成完整逻辑链（分析→策略→执行→预算→评估→风险）？
- [ ] 每项执行任务是否有**负责人 + 时间节点 + 验收标准**？
- [ ] 里程碑节点是否有明确**验收标准**而非只写日期？
- [ ] 预算每行是否含**金额 + 占比 + 计算依据**？
- [ ] 是否预估了 ROI / CAC / 回本周期？
- [ ] 风险清单是否覆盖四类并含**触发条件 + 止损阈值**？
- [ ] 方案是否可被第三方**直接拿去执行**？

## 反模式对照
| ✅ 正确 | ❌ 避免 |
|--------|--------|
| "Q2 末 GMV 5000 万，新客 CAC ≤ 120 元" | "Q2 大幅提升销售业绩" |
| "小红书种草 → 1500 条笔记 → CPM 45 → 预估曝光 3000 万" | "通过小红书营销" |
| 任务表含：任务/负责人/起止日期/依赖/验收标准 | 只有"任务 + 大概时间" |
| 预算表每行：金额 + 占比 + 计算依据 | "预算约 500 万" |
| 风险："预算超支 → 单月消耗>120% → 暂停投放+优化素材" | "注意控制预算" |
| 里程碑："M3 2026-03-01 MVP 上线（验收：核心 5 场景跑通）" | "Q1 完成 MVP" |
