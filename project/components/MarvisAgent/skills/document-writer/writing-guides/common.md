# 通用写作规范（所有文档强制底座）

> 📌 本规范适用于**所有文档类型**，与 `writing-guides/{category}.md`（research / summary / proposal）**叠加生效**；条目冲突时**类别规范优先**。
>
> **使用时机**：Step 3 加载后，4a 大纲定稿前、4c 每章动笔前各重读一次。

---

## 一、四条铁律

1. **事实驱动**：所有结论、论点、数据必须有素材 / findings / 原始数据支撑，**禁止主观臆断或凭常识编造数值**。若原始数据未提供基准值（满分 / 目标 / 预算），**必须**标注 "未提供 / N/A"，禁止自行填充。
2. **需求锚定**：每段文字必须能回答"它对应用户的哪条个性化诉求或大纲中的哪条关键问题"，写不清就删。
3. **优劣并述**：客观呈现优势与不足、机会与风险，不报喜不报忧、不回避问题。
4. **精炼优先**：能用一段话说清就不写三段。**质量达标前提下越精炼越好**，不写与关键问题无关的铺垫、套话和注水内容。

---

## 二、写作风格

- **专业客观**：第三人称、中立立场、避免口语化表达。
- **简洁有力**：避免冗长句式；同义反复、形容词副词堆砌、为排比而凑的句式一律删除。
- **逻辑严谨**：因果关系清晰、论证链条完整；结论前置，论据紧随。
- **术语一致**：专业术语首次出现可附简要解释；同一文档内同一概念用同一词汇。

---

## 三、注水信号（出现立即删）

- "综上所述 / 总而言之 / 值得注意的是 / 不言而喻 / 众所周知" 等填充短语
- 与关键问题无关的背景铺陈、意义陈述、展望寄语
- 把一句话拆成三句说的同义改写
- 为排比工整而硬凑的句式
- **判断标准**：删掉这一段后，关键问题是否仍然被充分回答？是 → 这段就是冗余。

---

## 四、数据与引用

- **口径一致**：同一指标在全文中使用同一单位、同一时间范围、同一计算方式。
- **数值规范**：百分比保留 1 位小数；金额按量级选单位（万 / 亿 / 百万 / 十亿）；人数用整数。
- **派生数值**（比率、得分率、增长率）必须可追溯到原始数据与计算公式。
- **事实与预测分离**：已发生的事实、他方观点引用、本文分析/预测必须明确区分。
- **引用标注**：调研分析类**强制**，其他类推荐；关键事实注明来源，必要时附 URL。

---

## 五、章节与关键问题规范（路径 B 写作时硬约束）

- **章节最小必要**：能用 3 章讲清绝不拆 7 章；典型冗余章节（背景 / 意义 / 展望 / 总结 / 执行摘要 / 附录）若无诉求支撑一律删。
- **同批数据的切片合并为一章多小节**：同一批数据 / 同一对象的不同切片视角（整体 / 趋势 / 异常 / 分群）必须合并为同一章的多小节，不得独立成章。
- **每章关键问题 2-3 条**：超 3 条先合并问题再考虑拆章；少于 2 条且与邻章相近则并入邻章做小节。
- **写作紧扣需求锚定**：每章必须紧扣 `outline.md` 顶部的"文档需求锚定"，逐条回答"关键问题"，禁止脱离用户诉求堆砌模板通用内容。

---

## 六、通用自审清单（大纲落盘前、每章写完后必读）

- [ ] **诉求对齐**：每段文字是否都对应某条"关键问题"或"个性化诉求锚点"？
- [ ] **编造数值**：是否存在编造的数值 / 未提供来源的关键事实？
- [ ] **口径一致**：数据口径、单位、时间范围是否全文一致？
- [ ] **优劣并述**：优劣是否并述，不存在片面呈现？
- [ ] **注水信号**：是否删除了注水信号（"综上所述"、空泛意义陈述、同义反复等）？

> 📌 该清单对应 SKILL.md `Step 4c 自审块` 的 **L2 通用底座** 5 项。

---

## 七、通用反模式样本（自审参照）

| ✅ 正确 | ❌ 避免 |
|--------|--------|
| "Q3 交易响应时间从 800ms 降至 200ms（提升 75%）" | "系统性能有了较大提升" |
| 原始数据缺基准值 → 标注 "未提供" | 没有满分 → 自己填一个 150 |
| 讲清关键问题后即收笔，不加"综上所述..." | 为凑篇幅硬塞填充短语和同义反复 |
| 同一指标全文用 "毛利率（%）" | 前面 "毛利率" 后面 "gross margin" |
| 事实："2025Q3 营收 12 亿"，预测："预计 2026 增长 20%" | 混写："营收 12 亿，明年会涨 20%" |
