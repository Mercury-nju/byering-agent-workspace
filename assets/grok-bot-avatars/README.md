# Grok Bot Avatar Extraction

Source: https://x.ai/bot

Extracted from the page's inline SVG bot marks and converted into standalone SVG assets.

The collection includes:

- Named Bot role variants shown in the sidebar and use-case section
- Color variants used by the page
- The `Inbox Manager` notifying-state variant
- `grok-bot-animated.svg`, a standalone CSS-animated avatar based on the page's inline SVG states
- `manifest.json` with role, color, state, and source metadata
- `preview.jpg` and `preview.html` for visual review

The page's 1:45 launch trailer is an external MP4 resource rather than an avatar asset. Its media host blocks direct file extraction outside the page, so it is not duplicated locally.

These assets are page-derived brand graphics. Check the source site's brand and usage terms before publishing them outside the current project.
